# Вычислительный тест ФОРЭКС на исходниках ГЛИССАДЫ-6

Регрессионный тест для проверки **реконструированного компилятора ФОРЭКС**
(проект `re-forex`). Дecke компилируется **системным** ФОРЭКСОМ 2.02 через
`dispak` на диске 2048; эталонный вывод сохраняется в `output.gold.txt` и
служит целью для будущей проверки реконструкции.

## Что выбрано и почему

В `re-glissade/SRC/` нет отдельного `GLKERN.FTN`: «ядро» размазано по
`JOB/GLKERN-2700.B6` и включает десятки подпрограмм. `GLGAIN.FTN` — это
только `BLOCK DATA` (иницализация таблиц, без вычислений). Поэтому тест
построен как **минимальный main + два вычисляющих блока**:

| Часть | Источник ( дословно ) | Что делает |
|---|---|---|
| `BLOCK DATA GLGAIN` | `../re-glissade/SRC/GLGAIN.FTN` | инициализирует `COMMON /APGAIN/`: матрицы `PGE`, `PKV`, `PKD`, `CG` (5×5) и `SLVL` (5) — усиления автопилота по погоде |
| `SUBROUTINE SBATM` | `../re-glissade/SRC/GLNUMR.FTN` | стандартная атмосфера МСА: `T=288.15-0.0065*H` (до 11 км), `ρ=1.225*(T/288.15)^4.2559`, выше 11 км — экспонента |
| `FUNCTION SBRND` | `../re-glissade/SRC/GLNUMR.FTN` | детерминированный ГПСЧ: сумма 12 равномерных (Лемер + ЦПТ) с `RSEED` из `COMMON /SBSEED/` |

Это резервные адаптеры ГЛИССАДЫ, специально не требующие библиотеки СБ
(`ATM`/`NR`), поэтому тест самодостаточен и воспроизводим.

## Что вычисляет `program glkern`

1. **Суммы усилений** — для каждого из 5 самолётов (строки матриц) печатает
   `SLVL(k)` и суммы по 5 столбцам `PGE`, `PKV`, `PKD`.
2. **Атмосферу** — `SBATM` на высотах 0, 5000, 10000, 15000 м: температура
   и плотность.
3. **ГПСЧ** — 5 значений `SBRND(1.0)` при фиксированном `RSEED=0.123456`.

Проверяемые возможности ФОРЭКС: `COMMON`, `BLOCK DATA` и `DATA` для
двумерных массивов, вложенные `DO`-циклы, вызовы подпрограмм и функций,
встроенные `FLOAT`, `EXP`, `AMOD`, `**`, вещественные `IF`, `PRINT` с
форматами `I`/`F`, продолжение строк.

## Как запускать

```bash
cd <re-forex>
bash tests/forex-glissade/run.sh          # прогон + проверка эталона
```

`run.sh`:

1. копирует `glkern.b6` и `options.txt` во временный каталог;
2. запускает `dispak glkern.b6` **дважды** (диск 2048, `*forex`);
3. нормализует дату в шапке (`DD.DD.DD` → `##.##.##`) — как в
   `tests/run-forex.sh`;
4. проверяет, что два прогона совпадают (детерминированность), и что
   вывод совпадает с `output.gold.txt`;
5. пишет протокол в `logs/glissade_test.txt`.

Переопределить бинарник можно через `DISPAK_BIN=...`.

Вручную:

```bash
TMP=$(mktemp -d); cp glkern.b6 options.txt "$TMP"/; cd "$TMP"
/home/azizz/Yandex.Disk/dispak/build/dispak/dispak glkern.b6
```

## Результат эталонного прогона (2026-11-19)

- `dispak` → `rc=0`, `stderr` пуст, ошибок компиляции нет;
- `raw bytes: 31920`, `gold bytes: 31920`;
- `DETERMINISTIC`: два последовательных прогона совпадают;
- `OK`: вывод совпадает с эталоном после нормализации даты.

## Файлы

- `glkern.b6` — дека: `*name`, `*forex`, исходник, `*execute`, `*end file`;
- `options.txt` — имя деки для `dispak`;
- `output.gold.txt` — эталонный вывод системного ФОРЭКСА;
- `run.sh` — запуск и проверка;
- `../logs/glissade_test.txt` — лог прогона.
