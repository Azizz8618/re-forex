# 85 — Несколько BESM-вставок и Fortran-присваивание аккумулятора

Дата: 22.11.2026. Развитие теста 83: не одно слово, а цепочка вставок плюс чтение накопителя **фортрановским** присваиванием (никаких `:=`).

## Синтаксис

```
      BESM(<hi>,<lo>)          -> 777006 <seq> 1 <hi> <lo>
      V = BESM(<hi>,<lo>)      -> 777006 + 777007 <seq> <varindex>
```

`V` — `X`, `Y`, `N` или `I`. Смысл второй формы: сначала исполняется вставленное слово, затем накопитель сохраняется в ячейку `V`. Все карты фиксированной формы, десятичные литералы, без `B`-суффикса и CHARACTER. DECK без BESM даёт 79/79 байт-идентичных записей старого FRONT’а.

## Размещение

Цепочка из четырёх сырых слов лежит в чистой зоне `N+3` по ОЗУ `0o30114..0o30122`; вход — структурированный переход из `body[14]`/`0o1775`. Дескриптор `*64` и GOST-слова остаются прежними. Все адреса выведены из `BASE=0o1757` и карты зоны `N+3` (тест 80).
