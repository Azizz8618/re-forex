# 67 — Зона N+2 из нашего эмиттера O412C

Дата: 22.11.2026. Продолжение теста 66: убираем последнюю зависимость установки
от чтения живого оверлея `2148:0o1552`.

## Что сделано

`src/newcomp/O412C.FTN` скомпилирован системным FOREX 2.02 на копии: **0 ERR**,
`O412CNW 410`, 410 строк `O412D n HI LO`. Из них извлечены 410 48-битных слов
(SHA256 вывода `1be6a50cf464745782642530b201bdff06800e1973538d8b596d195846afa245`):

| Индексы вывода | Назначение |
|:--|:--|
| 0..15 | каталог зоны N (16 слов) |
| 16..34 | тело зоны N+1, слова 0..18 (19 слов) |
| 35..409 | зона N+2, слова 526..900 (375 слов) |

В тесте 67 используется только последняя группа: зона `N+2` собирается целиком
из эмитированных слов, остальные её слова — нули. Значения совпадают с живой
таблицей `2148:0o1552` (0/375 различий) — эмиттер был прошит этими константами,
но на этапе установки живой диск уже не читается.

## Запуск

```
BESM6_DISK_SHARE=/usr/local/share/besm6 \
DISPAK_BIN=/home/azizz/Yandex.Disk/dispak/build/dispak/dispak \
BESMTOOL=/home/azizz/Yandex.Disk/dispak/build/besmtool/besmtool \
python3 tests/plan-f77/67-our-n2/run.py
```

Ожидается `VERDICT: PASS`: маркер есть в `normal` и `restore`, отсутствует в
`zero526` и `zero900` (таймаут). Тест использует `make_case()` из теста 66,
копирует диски и перенаправляет `HOME`/`BESM6_PATH`; живые диски не трогаются.

## Граница

Заменяется **источник слов** зоны N+2, а не логика: реальную компиляцию по-прежнему
выполняет резидентный 4.12 (маркер из теста 66 статичен). Хвост зоны N+1 (слова
19..1023) в этом тесте ещё берётся из живого root. Полная замена — фазы 3–4.
