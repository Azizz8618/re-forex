# 80 — Чистая память в зоне `N+3`

Дата: 22.11.2026. Снимает последнюю оговорку про «тесную общую память» без изменений LINK-таблицы, имён трансляторов и `f0`.

Карта, измеренная sentinels + CORE-дампом:

- зона `N+3` (`0o2353`) word `k` → ОЗУ `0o30114 + k`, всего **58 слов** (`k=0..0o71`);
- зоны `N+4..N+40` не дают образа в ОЗУ в момент входа.

Диапазон `0o30114..0o30205` чистый: широкие MTR-окна `0o30000..0o30777` и
`0o30100..0o30200` в базовом прогоне дают 0 попаданий; после установки нашей
программы PC-ы появляются только внутри её.

В зоне `N+3` лежит 58-словная программа: массив в высокой памяти через `MODA`/M20,
внутренняя подпрограмма с нашим `*64`, вызов из `body[9]` структурированным
переходом на `0o30114`.

## Граница

Это 58 чистых слов — достаточно для массива/подпрограммы, но не для всего Fortran-77. Для большего надо менять дескрипторы загрузчика, а не число зон. Проверено, что LINK, новое имя и `f0=0o1760` здесь не участвуют.
