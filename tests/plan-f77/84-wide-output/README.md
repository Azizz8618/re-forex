# 84 — Широкий вывод: 4 целых + 2 дробных разряда

Дата: 22.11.2026. Снимает ограничение теста 81 (`|v| ≤ 99.99`): наш контур печатает `9999.99` и отрицательные значения.

## Раскладка GOST

Четыре слова от адреса дескриптора `0o2006` (дескриптор из теста 66 **не менялся**, `*64` печатает до EOF):

```
A @2006: [N_t][N_u][sp][X_sign][X_i0][X_i1]
B @2007: [X_i2][X_i3][ . ][X_f0][X_f1][sp]
C @2010: [Y_sign][Y_i0][Y_i1][Y_i2][Y_i3][ . ]
D @2011: [Y_f0][Y_f1][EOF][sp][sp][sp]
```

Цифровые байты на диске нулевые; их наполняют четыре сырых ARX-слова (веса в `body[0o41..0o43]`, `body[0o40]`), исполняемые в `body[9..14]` перед `*64`.
