# 81 — Полная грамматика выражений из IR `777005`

Дата: 22.11.2026. Снимает ограничение `Y = X + литерал`: теперь выражения приходят из реальных Fortran-деков через `FRONT.FTN` и полный postfix IR `777005`.

## Поддерживаемое

- литералы (целые и десятичные), переменные `X/Y/N/I`;
- `+ - * /`, унарный минус, скобки (прецедентность решается в `FRONT.FTN`);
- F10.2-округление (Decimal, ROUND_HALF_UP), деление на ноль и переполнение стека — жёсткие ошибки;
- неизвестные `kind/op` отвергаются, а не угадываются.

Арифметика `+ - * /` сворачивается при эмиссии **только из записей IR** (проверенного runtime-опкода для упакованной десятичной арифметики нет, а плавающая `сл` портит GOST). Цифры устанавливаются в GOST-слова с нулевым seed и записываются во время прогона нашими ARX-словами (`XTA/ARX/STO/*64/UJ`, opcode 013). MTR показывает накопитель от seed к цифрам.

## Запуск

```
RT_GRAMMAR_WORK=/tmp/.private/azizz/opencode/gram81 \
TMPDIR=/tmp/.private/azizz/opencode \
python3 tests/plan-f77/81-general-grammar/run_cases.py
```

11/11 кейсов `VERDICT: PASS`. Примеры из реальных деков:

| Исходник | Печать |
|:--|:--|
| `X=2.0; Y=X*2.0+1.0` | `21 02.00 05.00` |
| `Y=X*2.0-1.0` | `21 02.00 03.00` |
| `Y=(X+1.0)*2.0` | `21 02.00 06.00` |
| `Y=X/4.0` | `21 01.00 00.25` |
| `X=-1.0; Y=X+2.0` | `21 -01.00 01.00` |
| `X=12.0; Y=X*2.0+1.0` | `21 12.00 25.00` |

A/B: обнуление слов данных `wA`/`wC` и кода `body[13]` меняет печать предсказуемо; подмена в IR литерала `100→300` при неизменной деке меняет `05.00→07.00`.

## Граница

2 целых + 2 дробных разряда (`|value| ≤ 99.99`), шаг 0.01; `100.0` вызывает `OverflowError`, а не перекрученное значение. Массивы, функции, `**`, multi-letter names и exponential literals пока не поддерживаются FRONT’ом.
