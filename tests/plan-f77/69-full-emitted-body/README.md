# 69 — Полностью эмитированное тело в зоне 2350

Дата: 22.11.2026. Веха M2 плана `docs/63-full-compiler-design.md`.

## Что проверяется

Всё тело компилятора формируется нашими Fortran-эмиттерами:

| Область | Источник |
|:--|:--|
| каталог, зона `N` (16 слов) | `O412C.FTN`, выход 0..15 |
| тело, зона `N+1`, слова 0..18 | `O412C.FTN`, выход 16..34 |
| тело, зона `N+1`, слова 19..1023 | **`O412D.FTN`, 1005 слов дословно** |
| зона `N+2`, слова 526..900 | `O412C.FTN`, выход 35..409 |
| зоны `N+3..N+40` | нули |

Ни одного слова не берётся из живого root `2148:0o1551/0o1552`: тест 2
проверял это, обнуляя живые зоны и убирая диск 2148 из пути — вывод не менялся.

**Зона:** `N = 0o2350` (дека `*TRANS:OURMRK*,,412350`). Зоны `0o2300..0o2347`
зарезервированы за старыми PERSO-экспериментами и не используются.

Фикстура `o412d_words.hex` — 1005 слов, сгенерированных компиляцией

`03b5aa5a989c6104488053e09a13659004a5110e0979a6440b9a3ffed982511e`),
слово 36 = `0o4000000000500155`.

## Граница

Это всё ещё статический маркер: компиляцию выполняет резидентный 4.12. Тест
доказывает только, что **все слова тела наши** и что зона 2350 работает так же,
как историческая 1744. Вычисляемый вывод — фаза 3, полный фронт-энд — фаза 4.
