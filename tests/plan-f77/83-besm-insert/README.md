# 83 — Машинные вставки `BESM(...)` (как pascal-re)

Дата: 22.11.2026. Наш компилятор теперь умеет вставлять сырое 48-битное слово БЭСМ-6 в исполняемый поток — аналог интринзика `besm()` в pascal-re (`docs/71-besm-insert-research.md`).

## Синтаксис и IR

FOREX 2.02 имеет 40-битную мантиссу INTEGER, поэтому слово передаётся двумя 24-битными десятичными половинами:

```
      BESM(<hi>,<lo>)       слово = hi*2**24 + lo
      -> 777006 <seq> 1 <hi> <lo>
```

FRONT.FTN (копия в этом каталоге) добавил правило 38; все 79 старых записей `777001..777005` для деки без BESM побайтово совпадают с исходным FRONT’ом.

## Исполнение

Codegen кладёт точное слово в `body[14]` = ОЗУ `0o1775`, прямо перед `*64` печати. Пример `BESM(46091,1032)` → `0013201300002010` = `ARX 2013 / STO 2010`: берёт заранее подготовленный вес `+1` и записывает его в GOST-слово `Y`.

## Запуск

```
TMPDIR=/tmp/.private/azizz/opencode python3 tests/plan-f77/83-besm-insert/run_ab.py
```

A/B (-all `КОНЕЦ ЗАДАЧИ`, MTR подтверждает PC `01775`):

| Кейс | Печать |
|:--|:--|
| база без BESM | `21 01.00 03.00` |
| `BESM(46091,1032)` | `21 01.00 04.00` |
| `BESM(46092,1032)` | `21 01.00 05.00` |
| обнулить вставленное слово | `21 01.00 03.00` |
| вставка до `PRINT` вместо после `END` | `21 01.00 04.00` |

Ожидается `VERDICT: PASS`. Диски копируются, HOME/BESM6_PATH перенаправляются.

Ограничение: вставляется одно слово за раз; адреса исчисляются от `BASE=0o1757`; все слова должны лежать в окне копирования `body[0..0o43]` либо в 58 словах зоны `N+3`.
