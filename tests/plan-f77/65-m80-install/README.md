# 65 — Установка пересобранного `GIVTRAN*` в каталог Монитора-80: отрицательный результат

Дата: 22.11.2026. Продолжение docs/61 §17–20 и плана 59 (B2).

## Цель и verdict

Проверить, можно ли заставить `*TRANS` исполнять **наш** код, пересобрав
`GIVTRAN*`/`SETTRAN*` из текстов Монитора-80 и установив объект в каталог
постоянной библиотеки диска 2048 (вместо патча dispak, который запрещён).

**Вердикт: НЕ ПОЛУЧИЛОСЬ.** Ни один из четырёх исследованных вариантов установки
не привёл к печати нашего маркера `21 1.00 3.00`. Резидентный FOREX 4.12
продолжает компилировать дек. Трек A закрыт по go/no-go.

## Что точно установлено

1. `60 0001 00 00166 01770` из выдачи `overlay.pl` — это **build-time** запись
   каталога: LUN 60 → рабочий том 80, зона 1, длина `0o166` слов, вход `0o1770`.
   Это не физическая зона диска 2048/2148/2348 (проверено дампами зон 1).
2. Живая запись `GIVTRAN*` лежит в диске 2048: `0o240.0455` (дубль `0o243.1515`),
   LINK-имя — `0o200.0040`. Тела в зоне `0o250+` с именем `GIVTRAN*` **нет**.
3. Единственная зона каталога с кодом, совпадающим с нашей сборкой, — `0o354`,
   но её имя — `//MINI*`; это совпадение пролога загрузчика, а не нашего модуля.
4. Безопасная установка на копиях тестировалась в четырёх точках:
   `0o354` @ `0o1000`, `0o252` @ `0o600` (раскладка WRITLIB*),
   `0o354` @ `0o1040` (раскладка mini/Makefile), зона `0o204` (сырая зона).
   Маркер не появился ни в одном случае; в варианте `0o252` задание падает с
   `Interrupt 00702/00703` (разрушен WRITLIB*), что подтверждает расписание зон.

Вместе с B2 (`docs/plan-f77-full/59-autonomous-body-plan.md` §4: `*TRANS`
никогда не исполняет слова нашего тела, `VJM 64002` уходит в резидентный
компилятор) это закрывает каталожный путь «наш компилятор вместо 4.12».

## Воспроизведение

```
BESM6_DISK_SHARE=/usr/local/share/besm6 \
DISPAK_BIN=/home/azizz/Yandex.Disk/dispak/build/dispak/dispak \
BESMTOOL=/home/azizz/Yandex.Disk/dispak/build/besmtool/besmtool \
bash tests/plan-f77/65-m80-install/run.sh
```

Скрипт работает только с копиями дисков, перенаправляет `HOME` в отдельный
каталог каждой variantы и ничего не удаляет. Ожидаемый результат: `VERDICT:
REPRODUCED` и таблица, в которой `marker` отсутствует во всех строках.

Исходник пересобранного модуля — `givtran_our.asm` (всего изменение: `SETTRAN*`
печатает маркер через проверенный дескриптор из `src/reloc/FXLODR.mad`).
Готовый объект — `ovl_our.hex` (6144 байт = 1024 шестибайтовых слова:
слово 0 = длина `0o166`, слово 1 = TEXT `GIVTRAN*`).
