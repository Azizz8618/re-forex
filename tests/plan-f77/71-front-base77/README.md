# 71 — FRONT.FTN: правила 30..37 для BASE77

Дата: 22.11.2026. Веха M1 плана `docs/63-full-compiler-design.md`.

`src/newcomp/FRONT.FTN` расширен до 228 строк: добавлены правила 30 (PROGRAM),
31 (присваивание), 32 (счётный DO), 33 (CONTINUE с меткой), 34 (нумерованный
PRINT), 35 (FORMAT), 36 (STOP), 37 (END). Writer IR `777001..777003` остался
побайтово прежним; изменены только две guard-строки и добавлена классификация.

## Запуск

```
TMPDIR=/tmp/.private/azizz/opencode \
BESM6_DISK_SHARE=/usr/local/share/besm6 \
bash tests/plan-f77/71-front-base77/run.sh
```

Тест:
1. инъецирует 10-карточный BASE77-исходник в шаблон `FRONT.FTN` (маркеры `C@@DECL@@`,
   `C@@DATA@@`);
2. компилирует его системным FOREX 2.02 на копиях дисков (`0 ERR`);
3. вызывает `FRONT1` и сравнивает IR с `expected_ir_spec10.txt`.

Ожидается `IR: MATCHES docs/63 section 3.1` и `VERDICT: PASS`.

## Две поправки к спецификации docs/63 §3.1

- В строке `X=1.0` числовое поле `itype=1` противоречит собственному комментарию
  «itype 2 REAL»; в эталоне теста использовано исправленное значение 2.
- Спецификация перечисляет 10 строк IR, тогда как каноническая дека содержит
  11 карт (дополнительная `N=N+I`). Тест использует 10-карточный вариант
  (`spec10`), чтобы сравнение было побайтовым; 11-карточный вариант тоже
  компилируется с 0 ERR и даёт 83 записи IR.

Диски копируются, `HOME`/`BESM6_PATH` перенаправляются, живые диски не тронуты.
