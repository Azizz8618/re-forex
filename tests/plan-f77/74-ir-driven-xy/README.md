# 74 — X/Y и FORMAT из IR Fortran-исходника

Дата: 22.11.2026. Снимает последнюю оговорку теста 73: печатаемые `X`/`Y`
берутся не из посеянного хвоста `O412D`, а из IR, который `FRONT.FTN` выдаёт для
реальной Fortran-деки.

## Правила разбора

Только записи IR (`777001` заголовки, `777002` ASCII-потоки):

| Правило | Поток | Что извлекается |
|:--|:--|:--|
| 31 | `X=2.0`, `Y=X+3.0` | LHS и RHS; константы сворачиваются в порядке `seq` |
| 32 | `DO 10 I=1,6` | граница `B` (уже работает через runtime ARX) |
| 35 | `FORMAT(1X,I4,2F10.2)` | число знаков `d=2` из `F10.2` |

Сворачивание выражений — emission-time в нашем CODEGEN (поддерживает литералы,
уже присвоенные переменные, `+ - * /`, унарный знак). GOST-байты берутся из
авторитетной таблицы `EMIT.FTN` `GT(64)` = `monitor80-re/tools/encoding.cpp`.

Печатная строка `NN X.d Y.d` упаковывается в `body[0o27]`/`body[0o30]`; ведущие
цифры `NN` всё ещё вычисляются в runtime из границы (тесты 70/72/73).

## Запуск

```
TMPDIR=/tmp/.private/azizz/opencode \
BESM6_DISK_SHARE=/usr/local/share/besm6 \
python3 tests/plan-f77/74-ir-driven-xy/run_all.py
```

A/B по реально отредактированным Fortran-декам (все компилируются с 0 ERR):

| Исходник | Печать |
|:--|:--|
| `X=1.0, Y=X+2.0, DO …1,6` | `21 1.00 3.00` |
| `X=2.0, Y=X+2.0, DO …1,6` | `21 2.00 4.00` |
| `X=2.0, Y=X+3.0, DO …1,6` | `21 2.00 5.00` |
| `X=2.0, Y=X+2.0, DO …1,5` | `15 2.00 4.00` |

Плюс 4 мутации эмитированных GOST-слов: обнуление X-слова, Y-слова, замена
цифры X `2→9`, цифры Y `4→8` — печать меняется соответствующим образом.
Ожидается `VERDICT: PASS`. Диски копируются, `HOME`/`BESM6_PATH` перенаправлены.

Доказательство «из IR, а не из текста деки»: изменение одного кода `777002`
в IR (`X=1.0` → `X=7.0`) при неизменной деке меняет свёртку на `X=7,Y=9` и GOST
на `01 7.00 9.00`.

## Граница

`X`/`Y` вычисляются компилятором на этапе эмиссии (constant folding), а не
исполняемой арифметикой БЭСМ-6; runtime-арифметика остаётся только для `N`.
Поддерживается узкое грамматическое подмножество выражений; функции, массивы и
общий Fortran-77 пока не заявлены.
