# 72 — Цифра из границы цикла BASE77 (M3–M5)

Дата: 22.11.2026. Замыкание цепочки CODEGEN/EMIT → тело `*TRANS` → печать.
Зона `0o2350`, дека `*TRANS:OURMRK*,,412350`.

## Интерфейс границы

`B` — граница счётного DO BASE77. CODEGEN/EMIT выводят два слова-инкремента
в теле `0o41`/`0o42` (ОЗУ `0o2020`/`0o2021`):

| B | tens (`0o41`) | units (`0o42`) | печать |
|--:|:--|:--|:--|
| 6 | `(6-4)<<40` | `0` | `21 1.00 3.00` |
| 5 | `(5-4)<<40` | `(24-20)<<32` | `15 1.00 3.00` |

Runtime-код — два сырых `слц`/ARX из этих ячеек в GOST-слово, затем проверенный
`*64 2004` и возврат `13,UJ,.`. Плавающая `сл` запрещена (`docs/corrections.md`).
Все адреса выводятся из `BASE=0o1757`, все слова лежат в окне копирования
`body[0..0o43]`.

## Запуск

```
TMPDIR=/tmp/.private/azizz/opencode python3 tests/plan-f77/72-bound-driven/verify_deck.py
TMPDIR=/tmp/.private/azizz/opencode python3 tests/plan-f77/72-bound-driven/installer.py
```

`verify_deck.py` сверяет 11 слов Fortran-дека `N3M35.FTN` со слов stream для B=6 и
B=5 (11/11 MATCH). `installer.py` ставит тело на копию 2048 и гонит A/B:

| Кейс | B | Печать |
|:--|--:|:--|
| `bound6` | 6 | `21 1.00 3.00` |
| `bound5` | 5 | `15 1.00 3.00` |
| `restore6` | 6 | `21 1.00 3.00` |
| `zero_tens` | 6, обнулить 0o41 | `01 1.00 3.00` |
| `zero_units` | 5, обнулить 0o42 | `11 1.00 3.00` |
| `zero_code9` | обнулить первую ARX | значения нет |
| `zero_code10` | обнулить вторую ARX/запись | `01 1.00 3.00` |

Ожидается `VERDICT: PASS` в обоих скриптах. Диски копируются, HOME/BESM6_PATH
перенаправляются.

## Честно о границе

Выполняется не общий цикл умножения и не счётный цикл, а точная аффинная
формула для двух контрольных границ: `tens=B-4`, `units=25-4B`. Она верна для
`T_B=B(B+1)/2` в точках B=5 и B=6; общий BESM-6-алгоритм треугольных чисел
не заявлен. Хвост `1.00 3.00` остаётся статическим. Это граница текущего
доказательства, а не «полный Fortran-77 компилятор».
