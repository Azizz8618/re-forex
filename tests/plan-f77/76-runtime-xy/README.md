# 76 — X/Y вычисляются во время исполнения

Дата: 22.11.2026. Снимает ограничение теста 74: `X`/`Y` больше не сворачиваются
в GOST-слова при эмиссии. ГОСТ-слова, записанные на диск, содержат **нулевые**
цифровые байты; ненулевые цифры появляются только после исполнения наших
инструкций ARX (опкод 013, raw `слц`).

## Токенный интерфейс

`token_interface.py`: `(kind, op, arg)` в порядке вычисления стека:
`CONST`, `VAR`, `STORE`, `ADD`. Интерпретатор принимает `Y = X + <литерал>`
(чтобы вес `Y` раскладывался на вклад X и вклад приращения и складывался разными
ARX-инструкциями). Тест 77 подключает к этому интерфейсу реальные записи `777005`.

## Механизм и доказательство

- GOST слово 1 `body[0o27]`: seed `[0,1,15,0,14,0]` (байт X = 0);
  GOST слово 2 `body[0o30]`: seed `[0,15,0,14,0,0]` (байт Y = 0).
- Веса X и приращения лежат в ячейках `body[0o43]`/`body[0o32]`/`body[0o33]`;
  граница N — в `body[0o41]/[0o42]` (тест 72).
- Инструкции `body[9..16]` исполняются до `*64`, складывая веса в GOST-слова.
- До прогона дамп диска показывает нули; после прогона консоль печатает
  `21 2.00 4.00`. MTR с `BESM6_MTR_SKIP=6` показывает ARX по адресам
  `2006/2007/2011/2012/2020/2021/2022` с изменением накопителя от seed к цифрам.

## Запуск

```
TMPDIR=/tmp/.private/azizz/opencode python3 tests/plan-f77/76-runtime-xy/runtime_xy.py
```

A/B: X=1/add=2 → `21 1.00 3.00`; X=2 → `21 2.00 4.00`; add=3 → `21 2.00 5.00`;
обнуление кода X (`body[11]`) → `21 0.00 4.00`, кода Y (`body[13]`) →
`21 2.00 0.00`. Ожидается `VERDICT: PASS`.

Ограничение: одна значащая цифра в целой части X/Y (gate-точки BASE77).
