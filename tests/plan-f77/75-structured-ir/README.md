# 75 — Структурированный IR RHS (`777005`)

Дата: 22.11.2026. `src/newcomp/FRONT.FTN` расширен записями `777005` для правых
частей присваиваний; старый поток `777002` сохранён, поэтому тесты 71 и 74
проходят без изменений.

## Схема

```
777005 <seq> <kind> <op> <arg1> <arg2>
```

| Поле | Значение |
|:--|:--|
| `seq` | номер логической строки rule 31 (совпадает с `777001`/`777002`) |
| `kind` | 1 = литерал, 2 = переменная, 3 = бинарная операция, 4 = унарная |
| `op` | 0 для литерала/переменной; 1 `+`, 2 `-`, 3 `*`, 4 `/`, 6 унарный минус |
| `arg1` | литерал = вещественное ×100 (`1.0 → 100`); переменная = индекс (`X=1`, `Y=2`, `N=3`, `I=4`) |
| `arg2` | зарезервировано, 0 |

Порядок — **постфиксный (RPN)**: для `Y=X+2.0` идут `VAR#1`, `LIT(200)`, `BIN+`.
Потребитель держит стек: литерал/переменная → push, бинарная операция → pop два,
унарная → pop один. Приоритеты и скобки обрабатываются в `FRONT.FTN`
(метод shunting-yard); поддерживаются `+ - * /`, унарный знак, скобки,
однобуквенные переменные, беззнаковые десятичные литералы. Массивы, функции,
`**` пока не поддерживаются.
