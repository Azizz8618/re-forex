# 77 — Реальные записи `777005` управляют runtime-арифметикой

Дата: 22.11.2026. Стык двух половин: `FRONT.FTN` выдаёт структурированные RHS
`777005` (тест 75), а `runtime_xy.py` превращает их в исполняемые ARX-инструкции
(тест 76). Ни `X`, ни `Y`, ни граница `DO` не подставляются вручную — всё
читается из IR, полученного компиляцией реальной Fortran-деки.

## Поток

```
Fortran-дека (X=…, Y=X+…, DO …1,B)
  -> FRONT.FTN (777002 ASCII + 777005 postfix)
  -> tokens (CONST/VAR/ADD/STORE)
  -> runtime_xy.emit -> нулевые seed GOST + ARX-веса
  -> зона 0o2350 -> *TRANS -> печать
```

`tokens_from_ir()` разбирает `777005` по `seq`, восстанавливает LHS из `777002`
и собирает постфиксные токены; `bound_from_ir()` читает `DO 10 I=1,B` из rule 32.

## Запуск

```
TMPDIR=/tmp/.private/azizz/opencode \
BESM6_DISK_SHARE=/usr/local/share/besm6 \
python3 tests/plan-f77/77-ir-to-runtime/run.py
```

Ожидается `VERDICT: PASS`:

| Исходник | IR | Печать |
|:--|:--|:--|
| `X=1.0, Y=X+2.0, B=6` | 5 токенов | `21 1.00 3.00` |
| `X=2.0, Y=X+2.0, B=6` | 5 токенов | `21 2.00 4.00` |
| `X=2.0, Y=X+3.0, B=6` | 5 токенов | `21 2.00 5.00` |
| `X=2.0, Y=X+2.0, B=5` | 5 токенов | `15 2.00 4.00` |

`pre_x=0`, `pre_y=0` во всех кейсах: цифры до запуска физически нулевые.

## Граница

Интерпретатор принимает только `Y=X+литерал`, temps — одна цифра. Полная
грамматика IR уже поддерживает `+ - * /`, скобки и унарный знак (тест 75), но
рантайм-кодогенер пока использует лишь подмножество; расширение — следующий шаг.
