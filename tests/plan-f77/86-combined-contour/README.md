# 86 — Широкий вывод + цепочка BESM в одной компиляции

Дата: 22.11.2026. P9: объединение тестов 84 (4+2 разряда) и 85 (цепочка `BESM`/`V = BESM`).

## Разрешённый конфликт

Тест 84 использует `body[14]` для слова `ARX 2017 / STO 2011` (построение GOST D), а тест 85 хочет там же входной переход. Минимальное решение: переход ставится в `body[16]` / ОЗУ `0o1777` (у теста 84 это только возврат), возврат сохраняется в конце high-RAM цепочки `0o30122` и guard-словом в свободном `body[17]` / `0o2000`. `body[9..15]` остаётся байт-идентичным тесту 84.

## Запуск

```
TMPDIR=/tmp/.private/azizz/opencode python3 tests/plan-f77/86-combined-contour/run_combined.py
```
