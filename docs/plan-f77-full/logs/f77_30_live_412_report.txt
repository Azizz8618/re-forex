# Отчёт: живой компилятор FOREX 4.12 в C-симуляторе `disp` (dispak)

**Статус: DONE.** Минимальная дека компилируется и печатает `HELLO 412`,
баннер `F O R Е Х ИПМ АН СССР 4.12 ОТ 25.06.85` подтверждён.
Все файлы ниже находятся на копиях в `/var/tmp/b1-f77-fix/412-disp/`;
репозитории не изменялись.

---

## ФАКТ 1. Как запускается симулятор

Бинарник из `dispak/build/dispak/dispak` в справке называется `dispak`
(задача ставила его «disp»). Это тот самый C-интерпретатор с 6-байтными
словами (дисковые зоны читаются через `disk.c`, `ZONE_SIZE 6144`).
Ключевые опции:

```
--path=dir1:dir2...   поиск образов дисков (или переменная BESM6_PATH)
-l, --output-latin    латиница на АЦПУ (иначе Н/Е/О гомоглифы: "НЕLLО 412")
```

Диск задаётся в паспорте деки (`DIS 41(2148)^`), а образ ищется как
`$BESM6_PATH/2148`. `--path` не обязателен, если выставлен `BESM6_PATH`.

## ФАКТ 2. Точный воспроизводимый рецепт

Рабочий набор (минимальный, всё в `/var/tmp/b1-f77-fix/412-disp/repro/`):

```
repro/
  dispak                    # копия dispak/build/dispak/dispak
  t412.b6                   # дека (ниже)
  run.sh                    # скрипт запуска
  disks/
    2048                    # копия dispak/build/dispak/2048  (8.0M)
    2053                    # копия dispak/build/dispak/2053  (8.0M)
    2099                    # копия dispak/build/dispak/2099  (системный, 878K)
    2148                    # копия /usr/local/share/besm6/2148  (8.0M) !!!
```

Команда:

```sh
cd /var/tmp/b1-f77-fix/412-disp/repro
BESM6_PATH="$PWD/disks" ./dispak -l t412.b6 > t412.out 2>&1
```

`./run.sh` делает то же самое и дополнительно проверяет `grep` на
`4\.12` и `HELLO 412`. ===> `OK: FOREX 4.12 banner and HELLO 412 present in t412.out`.

Дека `t412.b6` (кодировка UTF-8, завершающие backtick + `ЕКОНЕЦ` как в
`tests/whetstone/whetstone.b6`):

```
шифр 419999 зс5^
DIS 41(2148)^
eeв1а3
*name T412
*TRANS:FOREX3*,,411550
      PROGRAM MAIN
      PRINT 100
  100 FORMAT('HELLO 412')
      END
*execute
*end file
``````
ЕКОНЕЦ
```

Вывод (`repro/t412.out`, строки 29, 74):

```
F O R Е Х ИПM AH CCCP 4.12 OT 25.06.85 BPEMЯ:  00.00
HELLO 412
```

Без `-l` литерал печатается кириллическими гомоглифами: `НЕLLО 412`
(лог `deck/t412.run`). Файл `repro/t412-latin.out` - тот же прогон с `-l`.

## ФАКТ 3. Какие диски реально нужны

Проверено последовательным удалением образов из `BESM6_PATH`:

| Состав каталога дисков | Результат |
|---|---|
| `2099 + 2148` | `disk_open: no 2053 image found`, `НЕТ СТПАСП` |
| `2099 + 2053 + 2148` | `disk_open: no 2048 image found`, `ОШ ВВД 024` |
| `2048 + 2053 + 2099 + 2148` | работает, `4.12` + `HELLO 412` |

`2348` **не нужен**: ни дека, ни монитор его не запрашивают.
Минимальный набор: 2048, 2053, 2099, 2148.

## ФАКТ 4. Ключевой барьер: не тот образ 2148

С образом `simh/BESM6/MD/2148` (SHA256
`d7f6738e15ec605db4b357c54d7d840a7a324a2c2603f8b33ccac5941507f992`)
дека с `*TRANS:FOREX3*,,411550` **не работает**:

```
           *TRANS:FOREX3*,,411550

   OTCYTCTBYET  FOREX3*          (с -l; без -l: ОТСУТСТВУЕТ  FОRЕХ3*)
          CBOM-PM...   01770
 КОНЕЦ ЗАДАЧИ
 00020: 00 074 0000 *74
```

Лог: `simh-repro/orig.out`; трасса Extracode `deck/wt-trace.run`,
трасса Э70 `deck/wt-dd.err` (строкa `DD pc=03022L ... u=41 z=1550 RD`
показывает, что зона 1550 реально читается, но нужного тела там нет).

С образом `/usr/local/share/besm6/2148` (SHA256
`75617c04fee7d90dfce12d7ea82fe8c5ae88897825508094313f970ace59b69b`)
та же дека работает, баннер `4.12` и `HELLO 412` присутствуют.

Точная причина (проверено побайтово, с учётом `ZONE_OFFSET=4` и формата
`zone_t` = 8 служебных слов + 1024 слова по 8 байт):

* В `MD/2148` тело FOREX 4.12 лежит в **логической зоне 0o1240**.
* В `/usr/local/share/besm6/2148` то же самое тело (1024 данных слова
  совпадают побайтово) лежит в **логической зоне 0o1550**.
* deck-указатель `411550` адресует зону 1550; в образе SIMH он читает
  не компилятор, отсюда `ОТСУТСТВУЕТ FOREX3*`.

Прямое подтверждение: замена адреса на `411240` в deck `simh-repro/t412-1240.b6`
и запуск с образом `MD/2148` даёт тот же результат:

```
F O R Е Х ИПM AH CCCP 4.12 OT 25.06.85 BPEMЯ:  00.00
HELLO 412
```

Лог: `simh-repro/z1240.out`.

## ФАКТ 5. Известная хорошая дека whetstone под `disp`

Оригинальная `tests/whetstone/whetstone.b6` с правильным набором дисков
работает: 6 баннеров `4.12`, финальная строка `SINGLE WHETSTONE KIPS ...`
(лог `repro/whetstone.out`, 403 строки). С образом `MD/2148` та же дека
падает с `ОТСУТСТВУЕТ FОRЕХ3*` (лог `deck/whetstone.run`, 61 строка).

## ГИПОТЕЗА (не подтверждена окончательно)

Образы 2148 - две разные ревизии укладки системного тома: в SIMH-копии компилятор
сдвинут на `0o1550-0o1240 = 0o310` зон (разная системная укладка тома),
отсюда и развёртка. Служебные слова зон тоже различаются, но данные
идентичны. Как именно создавалась каждая копия, из доступных исходников
не восстановлено; для воспроизведения etalon'а dispak нужен образ именно
из `/usr/local/share/besm6/2148`.

## ФАКТ 6. Побочные наблюдения

* `besmtool list 2148` не реализован (`*** Not implemented yet`); поиск
  `besmtool search 2148 FOREX` по SIMH-образу находится `1240.0002` с
  `FOREX3*, LO*SYN, LO*GEN` - это то же тело, что в правильном образе
  лежит в зоне 1550.
* `FOREX3*` - не имя модуля в образе, а параметр `NEWCOMP*` по таблице
  `monitor80-re/permanent/ltable%.asm:37-38` (`*TRANS` -> `NEWCOMP*`).
* Образ 2148 после прогонов не меняется: `sha256sum -c disks/2148.sha256.before`
  выдаёт `ЦЕЛ` (OK). Риск порчи диска при повторных запусках отсутствует.
* Возможная ловушка: в `~/.besm6/` лежит только 2348, поэтому без
  `BESM6_PATH` нужные диски не находятся.
