Формат образа (установлен по `disp/dispak/diski.h:46-49`, `disk.c:405-440`,
`defs.h`/`diski.h:15`): зона = 8 служебных слов ×8 байт + 1024 данных слова ×8
байт = **8256 байт**; физическая зона = логическая + `ZONE_OFFSET = 4`;
48-битное слово = младшие 48 бит little-endian uint64.

6-битный TEXT (Дубна) — таблица `tools/dtran_text.py:59-62` /
`tools/besm6_text_scan.py:64-66`:

```
" .БЦДФГИ()*ЙЛЯЖ/0123456789Ь,П-+ЫЗ" + "ABCDEFGHIJKLMNOPQRSTUVWXYZШЭЩЧЮ"
```

код = ASCII−0x20 для A–Z, слово = 8 символов, первый — в битах 42..47.
Проверка: `0xB298…` → `'LI'`; зона `1550` слово `2` → `FOREX3*`.

**Собственный сканер** `scan_text.py` (в этом каталоге) побайтово перебирает
все слова всех зон всех дисков; его адреса **совпали** с `besmtool search`
(4 кодировки g/k/t/i) для всех проверенных имён. Результаты:
`scan_text_summary.txt`, `scan_text_results.json`, `scan/*.txt` (100 файлов).
Логи прогона: `run/dd_t412.{out,err}`, `run/trace_t.{out,err}`.

**ФАКТ:** при самой компиляции с диска 2148 читаются **только зоны 1550–1577**
(CP-модуль). Отдельных чтений FORMAT/FORTLIBR/DATAPR*/OCTTDEC с 2148 нет —
они **резидентны в системной области 2048** и подкачиваются монитором по

**ФАКТ (`*70`):** в трассе `*70` — это Э70 `ddio()` (`disp/dispak/extra.c:2064-2100`),
т.е. **дисковый обмен**, а не вызов рантайма. Примеры: `04007: *70 4021`,
`00100: *70 60`, `64351: *70 53`. Вызовы подпрограмм идут не через `*70`, а
через `VJM LINK` (см. ФАКТ 3). Отдельно `*70` в `src/FOREX_RUNTIME.mad:294,299`
— экстракод memory/register dump внутри PRINT8; к выбору рантайма отношения
не имеет.

**ФАКТ (переименования):** `XDATAPR`, `OCTTDE*`, `XGIVPG`, `XTAKPG` — это
не «другие программы», а те же самые DMS-тела с **изменённым каталожным
именем**. Причина (`tools/build_forex_perso.py:37-50`, `docs/15:24-28`,
`docs/plan-f77-full/04-verification.md:192`): подлинные имена уже есть в
постоянной библиотеке монитора на диске 2048; дубль в PERSO даёт
`ИСПОРЧЕНА ПОДПРОГРАММА` (TERR6, `docs/plan-f77-full/55-monitor80-loader.md:40,53`).
Переименование каталожной записи (и head-слова у OCTTDEC) убирает конфликт,
сохраняя байт-точность тела.

**ГИПОТЕЗА:** `LOADANGO` отсутствует в PERSO осознанно: при `*TRANS` тело
FOREX3*+LO*SYN+LO*GEN грузится **целиком из одной зоны**, поэтому оверлейный
загрузчик не нужен. При классическом `*forex` (root на 2048) LOADANGO
обязателен.

## ФАКТ 6. Минимальный рантайм для вызова нашего компилятора через NEWCOMP*

**Необходимо (используется по факту):**

1. **Тело компилятора в зоне диска** — единый DMS-дамп `root + LO*SYN + LO*GEN`,
   с именем в шапке, совпадающим с параметром `*TRANS` (как 1550: FOREX3*).
   Наши `LO*SYN`/`LO*GEN` и пересобранный `FOREX*` уже есть в PERSO.
2. **Резидент системной библиотеки 2048:** `DATAPR*`, `OCTTDEC`, `GIV/PG`,
   `TAK/PG` — по LINK 0o74010/74013/74012/74011 корня; `FORMAT` + `FORTLIBR`
   (PRINT8/WRITLIBR) — для печати скомпилированной программы.
3. **Среда dispak:** диски 2048, 2053, 2099 + системный том с телом (2148).

**Не требуется:** `LOADANGO` (при `*TRANS` оверлеи уже внутри тела), отдельные
копии `FORMAT`/`FORTLIBR` в PERSO (они резидентны на 2048 и байт-точно
совпадают с нашими дампами), librar.12 (там только INSLIB-ссылки).

**ФАКТ:** наш PERSO **уже содержит** полный минимальный набор — все 9 модулей
из ФАКТа 4. Псевдонимы `XDATAPR/XGIVPG/XTAKPG/OCTTDE*` нужны только для
пути `*call`/`*perso`; при `*TRANS` разрешение externals идёт через системный
каталог 2048, где подлинные имена уже присутствуют.

## ГИПОТЕЗЫ (требуют проверки в M3/M4)

1. NEWCOMP* ожидает **сырой DMS-дамп зоны** (как 1550), а не PERSO-библиотеку
   с каталогом; чтобы подсунуть своё тело, нужно записать дамп в свободную
   зону тома и указать `41/zone` + своё имя в шапке (проверит M3).
2. LINK-ячейки 0o74010..0o74013 нашего корня при `*TRANS` будут разрешены
   системной библиотекой 2048 в подлинные DATAPR*/OCTTDEC/GIV/PG/TAK/PG,
   а не в PERSO-псевдонимы. Тогда X-псевдонимы в PERSO для этого пути
   избыточны, но безвредны (именá не коллидируют).
3. `2053` может быть не «зеркалом», а вторым экземпляром системного тома
   для смены диска во время прогона; подтвердить побайтовой сверкой зон
   0200–0237 между 2048 и 2053.
