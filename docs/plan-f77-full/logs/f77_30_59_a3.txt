## ВЕРДИКТ

**BLOCKED** по уровню (a) FULL-AUTONOMOUS.
**Достигнут уровень (b) PARTIAL, более сильный, чем ожидалось:** наш собственный
код, скомпилированный МАДЛЕН и вставленный эмиттером в тело, **исполняется в пути
`*TRANS` и печатает на консоль через экстракод `*64`**, при этом **зоны `N+3..N+40`
полностью обнулены**. Остаётся ровно **одна** живая зона `N+2=0o1746`, причём из
нее реально нужны слова `520..~949` (≈430 живых слов 4.12).

Иными словами: «наш маркер печатает наш код» — **ФАКТ**; «зоны N+2.. только наш
код/нули» — **НЕДОСТИГНУТО**, MONSYS/NEWCOMP* требует живой хвост оверлея LO*SYN.

## 3. Замена на НАШ код (шаг 3) —最关键ный результат

Источник нашего кода: `src/FXBANNER.mad` (репозиторий, READ-ONLY),
скомпилирован host-ассемблером `tools/build_forex_perso.py::assemble_source`
копией в `/var/tmp/b1-f77-fix/59-a3/fxbanner_body.bin`. Это **наш** машинный код:

* тело FXBANNER (16 слов, `load=0o12`, `entry=0o0`), слово 3 = `Э64 '4001'`
  (команда `*64` с дескриптором), слово 4 = возврат, слова 5..6 = дескриптор,
  слова 7..13 = GOST-текст `FOREX 5.00 / 19.11.2026 (RE-FOREX)'231'`;
* адреса в `*64` и дескрипторе перепакованы под загрузку `*TRANS`:
  `0o4001 → 0o1772` (дескриптор), `0o4002 → 0o1774` (GOST-текст),
  что соответствует **слову тела 11** и **слову тела 13**;
* код записан начиная со **слова тела 9** (эмиттерный слот `O412D 26`),
  т.е. сразу после 9-словного префикса B0..B8. Файл: `a3_code.bin`
  (13 слов, первое `0o64177202200000` = `Э64 1772`).

ФАКТ (`runs/ab_our_base/out.txt`, зоны N+3..N+40 = 0, зона N+2 живая):

```
           *TRANS:OURMRK*,,411744
 FOREX 5.00 / 19.11.2026 (RE-FOREX)
 КОНЕЦ ЗАДАЧИ
```

Это **печать через `*64` нашим кодом**, а не баннером 4.12 и не листингом
скомпилированной программы (дека в этих опытах содержала только `PROGRAM MAIN /
END`, см. `a3noprogram.py`).

## 5. Что пробовалось и не сработало (честно)

| опыт | результат |
|:--|:--|
| зоны N+2..N+40 = 0 + код в слове тела 9 | TIMEOUT, `*64` не печатает |
| зона N+2 = наш `*64`-код / `ones` / копия зоны N+1 | TIMEOUT |
| укорочение DMS-шапки: `B3 = cmd 0o20 / 0o40 / 0o100` + код, зоны N+2..=0 | TIMEOUT |
| каталог только `MONITOR*` + `OURMRK*` (без LO*SYN/LO*GEN) + код, зоны N+2..=0 | TIMEOUT |
| DMS `N2MRK` (20 слов) в зоне N+1, как в M4 `C2b` | `Interrupt 00707` / TIMEOUT; маркер `N2MARK-7391` не печатается |
| попытка найти наши слова в RAM (core dump на PC 064000/027230/04405) | наши слова **не встречаются дословно**: загрузчик применяет трансформацию/релокацию |
| подмена каталожного имени/дескриптора f0 (M4) | только f0=0o1760 проходит; точка входа фиксирована |

ГИПОТЕЗА (наиболее правдоподобная): MONSYS `TRNSLTOR` передаёт в NEWCOMP* не
только каталог и зону N+1, но и **менеджер оверлеев**, который адресует хвост
зоны N+2 (слова ~520..949). Без него загрузчик уходит в I/O-ожидание до
таймаута. Наш `*64`-код исполняется только после того, как эта инициализация
прошла.

## 6. Спецификация эмиттера O412C (что нужно дописать к 30 словам)

ФАКТ (проверено на работающем варианте):

1. Каталог — **те же 16 слов O412B** (`OURMRK*`, дескриптор `f0=0o1760`,
   пары LO*SYN/LO*GEN, `ISO OVERLA` в слове 0o12). Менять f0/имя нельзя.
2. Тело зоны N+1:
   * `B0..B8` — как в O412B (служебное слово, TEXT-имя, живая DMS-шапка,
     маркер `0o73461`, stub `уиа 1760(M16)/пб 464`, первые живые слова).
     **`cmd` в B3 оставлять `0o1760`**: укорочение ломает загрузку.
   * `B9` — наша команда `*64`: `EMIT48(IR=0, KOP=6, ADR=0o1772,
     IR=0,KOP=0,ADR=0)` → HI=`0o641772`, LO=`0`.
   * `B10` — возврат `uj 0(15)`: `0o6700000002200000` (из FXBANNER).
   * `B11` — дескриптор: два полуслова с ADR=`0o1774` → `0o177400001774`.
   * `B12` — второе слово дескриптора: `0o0001000040000000`.
   * `B13..` — GOST-10859 текст от `GOSTEN` из `EMIT.FTN`; для строки
     `M4D-A3-MARK` нужно заменить 7 текстовых слов FXBANNER на
     сгенерированные `GT`-таблицей байты и, возможно, скорректировать поле
     длины в B12 (точная семантика этого поля **не расшифрована**, ГИПОТЕЗА).
   * остальные слова зоны — нули.
3. Зоны N+3..N+40 — **нули** (проверено: печать сохраняется).
4. Зона N+2 — **пока обязательно живая**: слова `520..949` из live 1552.
   Пока не будет найден способ воспроизвести эту область своим кодом,
   уровень (a) недостижим.

Для уровня (a) дополнительно требуется (блокер): либо реконструировать
менеджер оверлеев M80 и заменить живой хвост N+2 нашим кодом, либо найти
режим `*TRANS`, в котором NEWCOMP* не запрашивает LO*SYN. Ни того, ни другого
в доступных исходниках/дампах нет.
