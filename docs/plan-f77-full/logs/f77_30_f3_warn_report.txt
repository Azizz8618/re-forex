## 0. ВЕРДИКТ

**DONE. Причина найдена и устранена на копиях.**

Предупреждение **НЕ** идёт от инлайновых хелперов
DATAPR / GIVPG / TAKPG / OCTTDE и **НЕ** от правки M15 в `RMON`.
Оно порождается **колодой**, а именно картой комментария с `c`/`C` в колонке 1
Fortran-исходника:

```
c---- BASE: INTEGER/REAL arithmetic, counted DO, explicit FORMAT.
```

На контуре `*call forex*` работает **старый** компилятор
`Ф О Р Т Р АН /16.07.73/`. Он считает любую карту с `C` в колонке 1
«пустым оператором» и печатает код `05003`. Системный `*forex`
(`ВЕРСИЯ 2.02 ОТ 15.07.80`) ту же самую карту комментария принимает без
диагностики. То есть это **разница диалектов компиляторов**, а не дефект
нашего корня.

Минимальный фикс: **убрать карту комментария из F3-деки**. После этого
листинг побайтово совпадает с базовым за вычетом ровно трёх строк
(эхо комментария, `05003`, текст предупреждения); результат
`21      1.00      3.00`, баннер `Ф О Р Т Р АН /16.07.73/` и код
автогенератора не меняются. `err.txt` пуст.

Правка `src/reloc/FOREX_ROOT.f3.mad` **не требуется и не помогает** (показано
трёмя независимыми вариантами сборки, §3).

## 2. Локализация: колода, а не корень

### 2.1 Что именно в колоде виновато

Прогоны на копиях (все с **неизменным** `build/FOREX_F3.bin`, `rc=0`,
`err.txt` пуст; полные логи в `runs/<TAG>/out.txt`):

| TAG | изменение колоды | `05003` / `ПУСТОЙ` | `21 1.00 3.00` |
|---|---|---|---|
| `baseline` | как есть | ДА | ДА |
| **`d01_nocomment`** | **удалена строка `c---- BASE: ...`** | **НЕТ** | **ДА** |
| `d02_upperC` | `c` → `C` в колонке 1 | ДА | ДА |
| `d03_nofull` | удалён `*full list` | ДА | ДА |
| `d04_nolist` | `*nolist` вместо `*full list` | ДА | ДА |
| `d05_blankafter` | пустая строка после `*call forex*` | ДА | ДА |
| `d06_noyesmem` | удалён `*call yesmemory` | — (задача не компилируется) | НЕТ |
| `d08_2comments` | добавлена вторая `c----` карта | ДА (одна) | ДА |
| `d09_Conly` | карта просто `C` | ДА | ДА |
| `d13_conly` | карта просто `c` | ДА | ДА |
| `d15_midcomment` | `c----` после `N=0` | ДА | ДА |
| `d16_tailcomment` | `c----` перед `*execute` | ДА | ДА |
| `d18_blankfirst` | `c----` → пустая строка | НЕТ | ДА |
| `d19_col7C` | `C` в колонке 7 | НЕТ (другая ошибка `15002`) | НЕТ |
| `d20_star` | `c----` → `*----` | НЕТ | ДА |
| `d21_cmt2nd` | `c----` второй строкой | ДА | ДА |
| `d22_nolist` | `*no list` + комментарий | ДА (в другой форме) | ДА |

| `d24_padded` / `d25_paddedblank` | `C` + добивка до 80 колонок | ДА | ДА |

Вывод: **любая** карта с `c`/`C` в колонке 1 вызывает `05003`, независимо от
позиции в исходнике, регистра, длины и `*full list`/`*no list`. Пустая карта,
`*` и отсутствие карты комментария предупреждения не дают.

`05003` — это **код диагностики компилятора**, что видно в варианте
`*no list` (`runs/d22_nolist/out.txt`):

```
        ВРЕМЯ-000.00
          ОШИБКА НОМЕР 05003   В   00000-М    ОПЕРАТОРЕ, СЛЕДУЮЩЕМ ЗА МЕТКОЙ 00000
   ПУСТОЙ ОПЕРАТОР.
   21      1.00      3.00
```

Для сравнения, другие коды того же компилятора: `42001`
(«ПЕРВЫМИ ДОЛЖНЫ СТОЯТЬ ОПЕРАТОРЫ: PROGRAM ...», `d07_continue`),
`15032` («МЕТКА И ПРИЗНАК ПРОДОЛЖЕНИЯ», `d11_noend`),
`15002` («НЕОПОЗНАННЫЙ ОПЕРАТОР», `d19_col7C`).

### 2.2 Доказательство, что warning не зависит от нашего корня

В архивном прогоне `/var/tmp/b1-f77-fix/f3-output/runs/control/out.txt`
вообще **нет** `*perso` и `*call forex*` (чисто системный путь), но там
печатается тот же баннер `Ф О Р Т Р АН /16.07.73/` и тот же фрагмент:

```
          С---- ВАSЕ: INТЕGЕR/RЕАL АRIТНМЕТIС, СОUNТЕD DО, ЕХРLIСIТ FОRМАТ.
 05003
   ПУСТОЙ ОПЕРАТОР.
```

Контроль с `*forex` (`runs/d14_sysforex/out.txt`, а также
`/var/tmp/b1-f77-fix/f3-control/out.txt`) даёт
`F О R Е Х ... ВЕРСИЯ 2.02 ОТ 15.07.80`, комментарий в листинге есть,
предупреждения **нет**. Значит предупреждение определяется тем, какой
компилятор выбирает контур, а не телом нашего PERSO-модуля.

## 5. Точные рекомендуемые правки (владелец — главный агент)

### 5.1 Обязательная: убрать карту комментария из F3-деки

F3-дека сейчас живёт вне репозитория
(`/var/tmp/b1-f77-fix/f2b-nostand/deck.b6` → `f3-run4/deck.b6`).
Удалить **только** одну строку:

```diff
 *perso:602400
 *full list
 *call forex*
-c---- BASE: INTEGER/REAL arithmetic, counted DO, explicit FORMAT.
       PROGRAM BASE77
       N=0
```

Готовый результат лежит в `/var/tmp/b1-f77-fix/f3-warn/deck.FIXED.b6`.
Дословное новое состояние управляющей части и начала Fortran-тела:

```
*name BASE77
*call yesmemory
*perso:602400
*full list
*call forex*
      PROGRAM BASE77
      N=0
```

Если нужно сохранить визуальный комментарий, допустимые альтернативы,
тоже проверенные: заменить карту на пустую (`d18_blankfirst`) или на
`*---- BASE: ...` (`d20_star`). Обе дают тот же чистый результат.
**Не** помогают: `C` в верхнем регистре, добивка до 80 колонок, смена
`*full list`/`*no list`, перестановка комментария.

### 5.2 НЕ делать

- Не править `src/reloc/FOREX_ROOT.f3.mad`: правки флагов `*DUMON*`
  (`CHECKFL`, `FULISFL`, `NOLISFL`) и хелперов не снимают диагностику (§3).
- Не трогать `13,VTM,.` в `RMON` (`:53-55`) — это рабочий фикс F3, он
  отвечает за возврат M15 и на `05003` не влияет.
- Не гнаться за устранением предупреждения правкой `LO_SYN.words`: это
  меняет семантику компилятора и выходит за рамки F3-контура.

### 5.3 Опционально: зафиксировать деку в репозитории

Если главный агент хочет воспроизводимый proof, добавить новый файл
(например `tests/plan-f77/f3_base77.b6`) с содержимым
`/var/tmp/b1-f77-fix/f3-warn/deck.FIXED.b6`. Существующие декы
`tests/f77/suite/base.b6:10` и
`tests/plan-f77-full/unit/B01_integer_real/b01_integer_real.b6:10`
**трогать не нужно**: они идут через системный `*forex` и там
предупреждения нет.

## 6. Влияние на 14/14 glissade gold

**Нет влияния.**

- Золотой файл `tests/forex-glissade/output.gold.txt` — это полный консольный
  лог глиссады; он содержит собственные `С----` комментарии глиссадных
  исходников и печатается системным `F О R Е Х ... ВЕРСИЯ 2.02`, который
  их принимает без ошибки.
- `tests/run-glissade-forex.sh` использует другую деку (`*forex`,
  `*perso:602300`, образ `build/FOREX_PERSO_2300.bin`, зона `0o2300`) и
  не задействует ни F3-образ `build/FOREX_F3.bin`, ни `*perso:602400`,
  ни `*call forex*`.
- Предлагаемая правка меняет только внешнюю F3-проверочную деку, не
  исходники, не образы и не эталоны. Скомпилированный код BASE77
  побайтово тот же (§4), поэтому `21 1.00 3.00` и все 14 строк глиссады
  остаются прежними.
