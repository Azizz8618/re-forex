## ВЕРДИКТ: **DONE**

**Минимальный набор живых зон (целыми зонами):** `N+2..N+7`, `N+9..N+28`
(всего **26 зон**, где `N=0o1744`), плюс **практически целиком зона `N+1=0o1745`**.
Зоны `N+8=0o1754`, `N+29=0o2001`, `N+30=0o2002` читаются загрузчиком, но
**не нужны** (их обнуление не влияет на вывод); зоны `N+31..N+40`
(`0o2003..0o2014`) не читаются вовсе.

**Вывод для A2/A3 (ФАКТ по A/B):** автономное ядро в 30 слов НЕВОЗМОЖНО. Наш
эмиттер даёт 16 слов каталога + 14 слов префикса тела; но баннер и маркер
получаются только если доступны ещё ~1000 слов живой root-зоны `N+1` и 26 целых
зон оверлеев `LO*SYN`/`LO*GEN`. Чтобы убрать живые оверлеи, нужно перенести
**весь компилятор FOREX 4.12** (синтаксический анализ + генерация кода), а не
только entry stub / `*64` / RETURN. Рантайм (DATAPR*, OCTTDEC, FORMAT,
FORTLIBR/PRINT8, GIV/PG, TAK/PG) уже резидентен на 2048 и **в оверлеях не лежит**.

## 2. Шаг 1. Чтение диска (Э70 / `DD ... u=41`)

`BESM6_DD_DEBUG=1` печатает каждую Э70 как
`DD pc=... u=<ю> z=<зона> RD/WR ...`. Логический юнит **41 (восьм.) = диск 2148**.

**ФАКТ.** За весь FULL-прогон с диска 2148 прочитано **33 Э70 RD**
(`runs/full_trace/trace.err`):

| зона (восьм.) | число RD | pc чтения | что это |
|:--|--:|:--|:--|
| `0o1744` (`N`, каталог) | 1 | `03022` | каталог O412B (16 слов + нули) |
| `0o1745` (`N+1`, root) | 1 | `00671` | префикс эмиттера + хвост живого root |
| `0o1746` (`N+2`) | 1 | `00744` | root-зона 1 (живая 1552) |
| `0o1747` (`N+3`) | **2** | `00744`, `00671` | **LO\*SYN, заголовок модуля по слову 64** (живая 1553) |
| `0o1750..0o1777` (`N+4..N+27`) | по 1 | `00744` | LO\*SYN + LO\*GEN |
| `0o1766` (`N+17`) | **2** | `00744`, `00671` | **LO\*GEN, заголовок модуля по слову 64** (живая 1572) |
| `0o2000..0o2002` (`N+28..N+30`) | по 1 | `00744` | хвост LO\*GEN |

Итого **30 различных зон тела** `0o1745..0o2002` (непрерывный восьмеричный
диапазон) + каталог. Зоны `0o2003..0o2014` (`N+31..N+40`), записанные хостом,
**ни разу не читаются**.

**ФАКТ.** Два повторных чтения идут с другим `uil=10/0/3700` (вместо `10/0/3200`),
т.е. в другую страницу-буфер: это точки перехода между модулями оверлеев
(LO\*SYN по `1553.0064`, LO\*GEN по `1572.0064`; заголовки найдены побайтово:
`1553.0064 = 0o0000000000200022`, `1553.0065 = 'LO*SYN'`;
`1572.0064 = 0o0000000000200024`, `1572.0065 = 'LO*GEN'`).

**ФАКТ (ОЗУ).** `--coverage` сбрасывает карту при `abpc==01000` (системный хак в
`cu.c:225-227`), поэтому адреса тела в ней **стёрты**; она показывает только
`01000..04562` (MAIN и резидентные FT\*/PRINT8). Исправление — покадровая трасса
`MTR`: из 1 000 000 инструкций окна `0700..0777` **205 745** имеют `abpc` в
странице `0o60000`, **1048 различных адресов** в диапазоне `0o61314..0o67741`.
Крупные куски исполняемого кода:

```
0o64002..0o64002   (wtc 43 / uj 64012 — точка входа NEWCOMP*)
0o64012..0o64154   (vtm 1760(M16), atx 0(16), ... — настройка M16=f0)
0o64262..0o64573   (основной код root/LO*SYN)
0o64771..0o65551   (дальнейший код LO*SYN)
0o67001..0o67022, 0o67430..0o67510, 0o67610..0o67741  (код LO*GEN, др. страница)
```

**ФАКТ (`--trace-e64`).** Дескрипторы `*64` печати найдены:

| дескриптор (ОЗУ) | что печатает |
|:--|:--|
| `0o31510` | `F O R E X ИПM AH CCCP 4.12 OT 25.06.85 BPEMЯ:  00.00` (баннер) |
| `0o31434` | `3  100 FORMAT('M4D-O412B-MARK')` (листинг) |
| **`0o73521`** | **`M4D-O412B-MARK`** (байты `054-004-077-013-056-004-001-002-042-013-054-040-107-052-172`) |

Оба дескриптора лежат в загруженной области тела `0o60000+`. ГИПОТЕЗА: адрес
дескриптора выводится из f3/f2/f1 каталожного дескриптора при копировании тела;

## 4. Шаг 3. A/B обнулением

### 4.1 Целые зоны (результаты в `ab_zones.json`, логи `runs/ab_z*/out.txt`)

| обнулена зона z | rc | баннер | маркер | КОНЕЦ |
|:--|:--|:--|:--|:--|
| база (ничего) | 0 | да | да | да |
| 1,2,3,4,5,6, 8..27 | 0 / TIMEOUT | **нет** | **нет** | **нет** |
| **7** | 0 | **да** | **да** | **да** |
| **28, 29** | 0 | **да** | **да** | **да** |
| 30..39 (не читаются) | 0 | да | да | да |

**ФАКТ.** Обнуление **любой** из 26 зон `z ∈ {1..6, 8..27}` убивает вывод;
обнуление `z=7,28..39` — нет. Контрольный прогон `minset` (одновременно
`z=7,28..39`) даёт `M4D-O412B-MARK` и `КОНЕЦ ЗАДАЧИ`: эти 13 зон избыточны.

**ФАКТ (механизм отказа).** При обнулении «нужной» зоны ломается **цепь загрузки
ещё до баннера**. Число Э70-чтений падает:

| случай | прочитано зон (всего 33) | последняя прочитанная | причина отказа в `out.txt` |
|:--|--:|:--|:--|
| база | 33 | `2002` | — |
| z=1 | 12 | `1757` | TIMEOUT |
| z=2 | 25 | `1773` | `00702 mod` → `ЗАТЕРТО СПО` |
| z=21 | 24 | `1772` | `00743 *70` → `Пока рано` |
| z=27 | 28 | `1775` | TIMEOUT |

То есть загрузчик (`pc 00671/00744/00702/00743`) читает **содержимое** зон и
по нему решает, читать ли следующую. Обнуление обрывает цепь — это и есть
главная причина «необходимости» большинства зон, а не только исполнение их кода.

### 4.2 Усечение слов внутри зон

**ФАКТ.** Оставлять только заголовки бесполезно: при обнулении слов `0..8`,
`0..64`, `64..1024` **во всех** оверлей-зонах сразу — TIMEOUT. Оставление первых
`8/64/128/256/512/640/768/896` слов тоже ломает. Даже `keep=1023` (обнулено
только последнее слово каждой зоны) даёт `ЗАПРЕЩ.КОМАНДА`. Значит почти все
слова каждой из 26 зон участвуют в работе (код/данные/таблицы загрузчика).

### 4.3Root-зона `N+1` (кроме нашего 14-словного префикса)

**ФАКТ.** Оставляем `body[0..k-1]`, остальное нули:

| k (дес.) | баннер | маркер |
|--:|:--|:--|
| 14 (только наш эмиттер) | нет | нет |
| 64, 128 | нет | нет |
| 256, 512, 768 | нет | нет |
| 1000 | нет | нет |
| **1001..1023** | **нет** (до 1004), **да** (с 1005) | **да** |

То есть **слово 1000 (0o1750) root-зоны критично для компиляции**, а слова
`1001..1004` нужны для баннера. Наш 14-словный префикс сам по себе не работает.

## 5. Шаг 4. Какие функции нужно реализовать самим

**ФАКТ (из заголовков модулей и доков репозитория):**

1. **Корень FOREX3\*** (зона `N+1` + зона `N+2`/live 1552): инициализация,
   banner через `VJM LINK 0o74010 → DATAPR*`, время через `0o74013 → OCTTDEC`,
   страницы `0o74012 → GIV/PG`, `0o74011 → TAK/PG`, загрузчик оверлеев
   `0o74022 → LOADANGO`.
2. **LO\*SYN** (наши `z=2..17`, live `1553..1572`): синтаксический анализ
   Fortran-текста (разбор `PROGRAM/PRINT/FORMAT/END`, построение таблицы
   относительных адресов). Занимает 15 зон, из них `z=7` (live 1560) — мусор.
3. **LO\*GEN** (наши `z=17..29`, live `1572..1606`): генерация объектного кода
   (команды MAIN, INF-слово, `*64`-дескриптор печати). Из 13 зон реально нужны
   `z=17..27` (11 зон), хвост `z=28,29` — мусор.
4. **Рантайм НЕ наш:** `FORMAT`/FT\*, `FORTLIBR/PRINT8`, `DATAPR*`, `OCTTDEC`,
   `GIV/PG`, `TAK/PG` резидентны на 2048 (подкачиваются монитором по LINK).
   Их **не нужно** переносить в автономное тело.

**ГИПОТЕЗА (НЕ доказана):** точная граница «код vs данные» внутри каждой зоны.
Загрузчик копирует тело с трансформацией (`arx`/`atx` по `pc 00736..00741`),
поэтому дословного соответствия «слово зоны → слово ОЗУ» нет. Для A2 придётся
либо реверсировать эту трансформацию, либо делать A/B по отдельным словам.

## 6. Шаг 5. Рекомендация для A2/A3

1. **A2 (формат INF-слова):** искать не «B0..B30», а схему
   `каталожный дескриптор f3/f2/f1 → страница загрузки → адрес `*64`-дескриптора`.
   Точки опоры уже есть: вход `VJM 0o64002` (pc `0o455`), настройка `M16=0o1760`
   по `0o64012`, `*64` баннера по `0o31510`, `*64` маркера по `0o73521`.
   Нужна трасса с `BESM6_MTR_LO=064000 HI=067777`, чтобы снять трансформацию
   `00736..00741` для каждого слова.
2. **A3 (автономное ядро):** **переформулировать задачу**. 30 слов insufficient
   на два порядка. Минимальный автономный FULL требует:
   - ~1024 слова root-тела (заменить живой хвост `N+1`),
   - ~1024 слова root-зоны 1 (`N+2`),
   - ~15 зон LO\*SYN,
   - ~11 зон LO\*GEN,
   итого **~28 зон ≈ 28 672 слова**, плюс внешний резидентный рантайм 2048.
   Без переноса LO\*SYN/LO\*GEN автономности не будет.
3. **Быстрая победа для A6:** обнулить `z=7` и `z=28..39` (13 зон) — вывод
   стабилен (прогон `minset`). Это готовое A/B-доказательство «мусорных» зон.
4. **Ловушка:** обнуление «нужной» зоны ломает **загрузчик до баннера**
   (`ЗАТЕРТО СПО`, `Пока рано`, TIMEOUT). Поэтому A6 нельзя формулировать как
   «маркер не меняется» — он меняется именно потому, что обрывается цепь Э70.
