STEP 2 — design decisions for 32-f77-on-arfa.md §4
  R32-OPEN  -> CALL FOPEN(u,FMN<u>,st,ac,fm,rl,k). Name passed as 2 INTEGER words
    of GOST bytes; host transcodes FILE= literal STATICALLY at lowering time
    (avoids runtime CHARACTER<->GOST conversion).
    Codes: st UNKNOWN=0/OLD=1/NEW=2/SCRATCH=3; ac SEQ=0/DIRECT=1;
    fm FORMATTED=0/UNFORMATTED=1.
  R32-CLOSE -> CALL FCLOSE(u,del,k), del=1 DELETE / 0 KEEP.
  R32-INQUIRE -> CALL FINQ(u,v,k) [base, backward compatible] +
    optional FINQE(u,e,k) [EXIST via Э63 07], FINQX(u,ac,fm,rl,k) [cache].
    EXIST=.FALSE. is NOT an IOSTAT error (M16=1 NO_NAME -> k=0).
  R32-READ/WRITE: two mutually exclusive profiles:
    A (ARFA unformatted): CALL FREAD/FWRIT(u,buf,n,k); k=-1 from FMPOS>=FMZON;
    B (formatted/stdin): doc 19 §3.2 sentinel verbatim.
  IOSTAT map: M16 octal -> small positive profile codes 1..15; EOF=-1;
    AVOST not returned (E_TERM). Raw code kept in FMRAW.
