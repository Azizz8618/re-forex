## ВЕРДИКТ

**DONE.** Контракт `NEWCOMP*` понят и доказанexperimentally:

1. `411550` — это упакованное слово `*70`: `0o0010030000411550`
   (поля 12 бит: `0o0010 | 0o0300 | 0o0041 | 0o1550` = код операции,
   **диск 41**, **зона 0o1550**). `DIS 41(2148)` в деке связывает диск 41 с
   файлом `2148`. Читается **одна зона** — это КАТАЛОГ, а не тело.
2. NEWCOMP* ищет имя из карты в каталоге по адресу `41/N`; имя из карты
  _authoritative_, имя внутри DMS-тела игнорируется.
3. Тело модуля лежит **в следующих зонах после каталога**, начиная с `N+1`.
   дескриптор каталожной записи (4 поля по 12 бит) задаёт параметры загрузки,
   но НЕ абсолютную зону тела: один и тот же дескриптор работает и на зоне
   0o1240 (SIMH MD/2148), и на 0o1550 (/usr/local/share/besm6/2148), и на
   произвольной зоне 0o1744 (наш эксперимент).
4. Экспериментально доказано: можно создать свой каталог в ЛЮБОЙ зоне,
   положить тело в `N+1`, дать записи ЛЮБОЕ имя и вызвать
   `*TRANS:OURCOM*,,41/N` — компилятор грузится и работает.

## 1. ФАКТЫ: разбор параметра

### 1.1 Трасса и упаковка слова

Из отчёта параллельного субагента (`docs/plan-f77-full/logs/f77_30_newcomp_contract.txt`,
трасса C-симулятора `wt-dd.err:157`), подтверждено нашими negative control:

```
DD pc=03022L r016=53405 u=41 z=1550 RD uil=10/0/300 uir=41/0/1550
03021: *70 53405 (=0010030000411550)
```

Наши A/B:

| карта | консоль |
|:--|:--|
| `*TRANS:FOREX3*,,411550` | баннер `F O R E X ... 4.12 OT 25.06.85`, `HELLO 412` |
| `*TRANS:FOREX3*,,411551` | `OTCYTCTBYET  FOREX3*` / `CBOБOД 01770` |
| `*TRANS:FOREX3*,,421550` | `ОШ.В ИНФ.СЛ.ЭКСТ`, `03021 17 070 0001 *70`, `acc = 0010030000421550` (диск 42 не смонтирован) |
| `*TRANS:FOREX3*` (нет адреса) | зависание, `Interrupt 00711: 06 25 00001 utm` |
| `*TRANS:QWERTY*,,411550` | `OTCYTCTBYET  QWERTY*` |
| `*TRANS:,,411550` | `OTCYTCTBYET  FORTR*` (имя по умолчанию) |

**ФАКТ.** Поле `0o0041` = номер диска, `0o1550` = номер зоны; `DIS 41(2148)`
подключает файл 2148. Ошибка при неверном номере диска возникает на `*70` по адресу 03021.

Точная формула `f2/f1` не выведена, но для переноса модуля достаточно
сохранить дескриптор от рабочего модуля (см. §3).

## 4. EXP C (критическая): свой каталог + своё тело в другой зоне

### 4.1 Уже готовый второй компилятор на том же диске

Карта `*TRANS:FOREX*,,411350` (каталог 0o1350, там запись
`FOREX*` / `0o425372066401760` на слове 0o44, тело — DMS `FOREX*` в 1422.1741):

```
F O R E X   ИПM AH CCCP           BEPCИЯ  2.02 OT  15.07.80
```

**ФАКТ:** тот же `NEWCOMP*` по другому адресу грузит **другой компилятор**
(2.02 от 15.07.80), а не 4.12. Адреса 411332/411336/411345 дают
`OTCYTCTBYET FOREX*`.

### 4.2 Перенос каталога и тела в произвольную зону 0o1744

На копии 2148:

```
besmtool dump 2148 --to-file=z.bin --start=01350 --length=1
besmtool write 2148 --from-file=z.bin --start=01744
besmtool dump 2148 --to-file=z.bin --start=01351 --length=0120
besmtool write 2148 --from-file=z.bin --start=01745
```

(диск 2148 передавался через `BESM6_PATH`, чтобы не трогать эталон).

Карта `*TRANS:FOREX*,,411744` → баннер **2.02** и `HELLO 412`.

Контроли:

- original body `1352.0000..0177` обнулено, новое тело на 1745 цело →
  баннер 2.02 сохранён → грузится **перенесённое** тело.
- каталог скопирован на 1744, тело НЕ скопировано → `Interrupt 00707: 12 25 25252 utm`
  → NEWCOMP* читает тело из зоны `N+1`.

### 4.3 Своё имя

В перенесённом каталоге 1744 слово 0o44 (`FOREX*`) заменено на
`0o5765624357551200` = TEXT `OURCOM*`; карта
`*TRANS:OURCOM*,,411744` → баннер 2.02 + листинг + `HELLO 412`.

**ФАКТ (главный):** имя из `*TRANS` произвольное, каталог и тело можно
разместить в любой зоне диска 41, Body — сразу после каталога.

## 5. Минимальная трансформация для M4

1. Собрать наш компилятор (plan 57 N2/N3) как **DMS-модуль** с обычной
   3-словной шапкой: `[name][set/data/long][cmd|bss<<15|const<<30]`; `L=cmd+const+bss`.
2. В свободной зоне `N` диска 2148 (копия!) сделать каталог:
   `MONITOR*/0o370`, затем пары `TEXT<наше имя>` + дескриптор, скопированный
   с рабочего модуля (поля `f2/f1` сохранить; `f0` = наш `cmd`, при необходимости
   пересчитать по образцу 0o1760/0o1551).
3. Тело положить в зоны `N+1...` подряд, без разрыва.
4. Итоговая дека: `DIS 41(2148)^` + `*TRANS:OURCOM*,,41/N`.
5. A/B по плану 57 M5: обнулить слово в нашем теле → компиляция ломается;
   восстановить → снова работает.

**ГИПОТЕЗА (требует M4):** внешние SUBP/LINK (*A*, OCTTDEC, LO*SYN/LO*GEN)
разрешаются уже внутри загруженного тела — 4.12 и 2.02 несут свои оверлеи
в последующих зонах. Для BASE77 нужно либо включить те же оверлеи в
наш набор зон, либо оставить те же системные LINK-ячейки 0o74001..0o74013.
