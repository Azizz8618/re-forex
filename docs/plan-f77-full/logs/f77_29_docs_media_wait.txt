=== ОПЕРАТОР 4.3.5 УСТ / НЕТ Б / ЗАНЯТ Б ===
Сообщения на директиву:

* `<N КЛАССА>:<ЧИСЛО Г.З-Ч> [<N БОБИН>]` — установить на накопители
  указанные бобины для заданного класса задач;
* `ЗНЕТ` — на буфере ввода нет задач.

| Поле               | Значение |
|--------------------|----------|
| `<N КЛАССА>`       | Номер класса задачи. |
| `<ЧИСЛО Г.З-Ч>`    | Число задач в классе, уже готовых к решению. |
| `<N БОБИН>`        | Номера бобин, которые требуются задаче (знак "+" означает, что бобина установлена). |

Каждая строка сообщения дает информацию о бобинах одной задачи. После
исполнения директивы `УСТ` без параметра выдается информация о 10 задачах,
начиная с задач более приоритетных классов.

Пример:

```
УСТ
 УСТ2:01  +2048   0063
 УСТ2:01  +2048  +2119  0004
```

Для задач 2-ого класса необходимо установить бобины 63 и 4. Бобины 2048,
2119 уже установлены. Одна задача второго класса готова к решению и не
входит в решение из-за отсутствия системных ресурсов.

Если в сообщении на директиву указаны бобины, которые необходимо установить
для задач, то автоматически инициируется выдача свободных накопителей на
терминал оператора.

=== ОПЕРАТОР 5.32 НЕТ Б ===
### 5.32. НЕТ Б

```
НЕТ Б <N БОБИНЫ>
```

— нет бобины

/ОП/. Сообщение системы об исполнении директивы "СКВ <N задачи на буфере
ввода>".

Из-за отсутствия заказанной в паспорте бобины задача не выбирается
программой-планировщиком в рабочую смесь системы.

**Действия пользователя:** следует сообщить оператору номер отсутствующей
бобины для установки ее на соответствующий накопитель (НМД, НМЛ).


=== ОПЕРАТОР ЗАПР.АРХ ===
| `<ПРИЧИНА>`             | Причина, по которой задача не выбирается в решение. |

`<ПРИЧИНА>` = `НЕ ЗАД.КАН` / `ЗКАН` / `РЕС.<ТИП РЕСУРСОВ>` / `СТОП` /
`НЕТ Б<N БОБИН>` / `ЗАНЯТ Б<N БОБИН>` / `ЗАПР.АРХ`

| Причина                 | Значение |
|-------------------------|----------|
| `ЗКАН`                  | Заняты все программные каналы, выделенные данному классу. |
| `РЕС.<ТИП РЕСУРСОВ>`    | Задача не входит в решение из-за недостатка указанных системных ресурсов. |
| `НЕ ЗАД.КАН`            | Данному классу задач не выделены программные каналы. |
| `НЕТ Б <N БОБИН>`       | Бобины с указанными номерами не установлены на накопителях; требуемые бобины заказаны в паспорте данной задачи. |
| `ЗАНЯТ Б<N БОБИН>`      | Указанные бобины заняты другими задачами. |
| `СТОП`                  | На ЭВМ установлен режим "СТОП". |
| `ЗАПР.АРХ`              | Архивная система запрещает включение задач в решение. |


=== ОПЕРАТОР 5.10 ДЛЯ УПР/ВОС УСТ.СРОЧНО ТОМ ===
### 5.10. ДЛЯ УПР/ВОС УСТ.СРОЧНО ТОМ

```
ДЛЯ УПР/ВОС УСТ.СРОЧНО ТОМ <N ТОМА>
```

/О/. Сообщение системы, уведомляющее оператора о невозможности выполнения
процесса упрятывания/восстановления из-за отсутствия указанной архивной
бобины (тома) на внешних устройствах памяти.

| Поле       | Значение |
|------------|----------|
| `<N ТОМА>` | Номер архивного пакета или ленты. |

Пример:

```
ДЛЯ УПР/ВОС УСТ.СРОЧНО ТОМ 2125
```

Для упрятывания или восстановления задачи необходимо установить бобину с
номером 2125.

**Действия оператора:** установить на накопитель указанную бобину.


=== ОПЕРАТОР 5.16 ЗАНЯТ ===
```
ЗАНЯТ <N БОБ>
```

— бобина занята обменом

/ОП/. Сообщение системы об исполнении директивы "СКВ" (N23).

| Поле      | Значение |
|-----------|----------|
| `<N БОБ>` | Номер занятой бобины. |

Задача с номером, указанным в директиве "СКВ", не выбирается планировщиком в
решение из-за занятости бобины, заказанной в ее паспорте. Требуемая бобина
в это время может участвовать в обмене с другой задачей. Сразу же после
освобождения данной бобины задача выбирается в решение.


=== ПРОГРАММИСТ 4.8 ОСОБЕННОСТИ ПРОХОЖДЕНИЯ АРХИВНЫХ ЗАДАЧ ===
### 4.8. Особенности прохождения архивных задач в ОС

Непосредственно при вводе (формировании) задачи производится
синтаксический контроль имен. Если ошибки при этом не были обнаружены, то
задача поступает на буфер ввода ОС Диспак. Для задач, имеющих в паспорте
разделы "ТЕЛЕ" или "ЖДЕМ", вся дальнейшая обработка откладывается до того
момента, когда задача станет готовой к выборке в решение (т. е. задача
будет вызвана с терминала, или нормально окончится ожидаемая задача). Если
же задача не содержит разделов "ТЕЛЕ" или "ЖДЕМ", то она поступает на
обработку к архивной системе. В процессе обработки проверяется
существование заказанных областей. При заказе в паспорте области-каталога
или несуществующей области задача выбрасывается с буфера ввода с
диагностикой на операторский терминал:

```
НЕТ ОБЛАСТИ <ИМЯ>
ОГЧЕЗКЗАДАВА ВЫБР
```

При поиске области используются правила, описанные в разделе 4.3 данного
руководства. Одновременно в процессе обработки определяется правомочность
доступа к области; если пользователь не имеет права работать с областью,
то задача выбрасывается с диагностикой:

```
НЕСАНКЦИОНИРОВАННЫЙ ДОСТУП <ИМЯ>
ОГЧЕЗКЗАДАВА ВЫБР
```

Та же диагностика может быть получена, если пользователь заказал на запись
область, которая доступна ему только для чтения.

Если обработка задачи архивной системой по какой-либо причине
откладывается, то в ответе системы на директиву `СКВ` будет сообщаться

```
ЗАПР.АРХ.
```

т. е. имеется запрет на включение задачи от архивной системы.

При обработке задачи архивной системой для каждой области, заказанной в
паспорте, определяется том, на котором эта область расположена. Оператор
может определить требуемые тома с помощью директив `СКВ` и `УСТ`.

Пользователю в тех случаях, когда область находится на неустановленном
томе или вытолкнута на вторичный том, а также когда какая-либо область,
заказанная в паспорте, находится в монопольном владении какой-либо из
находящихся в решении задач, выдается диагностика `ЗАПР.АРХ.`.

При выполнении экстракода обмена возможно возникновение аварийных ситуаций:

| Сообщение | Причина |
|-----------|---------|
| `ОШИБКА В ИНФ.СЛОВЕ ЭК` | При выходе номера зоны за предел допустимых номеров (от 0 до L-1, где L — длина области). |
| `ДАЙ ЗАПИСЬ НА МЛ` | Не заказана запись на данный виртуальный номер. |
| `НЕВЕРНЫЙ ПАРОЛЬ` | Не подтвержден пароль области по соответствующему виду доступа. |

=== СИСПРОГ 9.1/9.3 ЗАПРОС УСТАНОВКИ ТОМА ===
### 9.1. Выдача сообщения об установке тома МЛ(МД)

`ИР 050 А`, где АИСП = 1206(8).

Экстракод предназначен для выдачи на операторский терминал сообщения:

```
УСТ.СР.К.N БХХХХ
```

где ХХХХ — номер тома МЛ(МД), который необходимо установить; N — номер
программного канала, по которому решается задача, выдавшая экстракод.

Перед выполнением экстракода на СМ в 1-16 Р заносится номер тома в
двоично-десятичном виде, на индекс-регистр 3 код 71717.

Если такой том уже установлен на ЭВМ, то на СМ задачи будет занесен его
номер в восьмеричном виде и выдачи на терминал не последует. Если же том не
установлен, то СМ=0 и на операторский терминал производится выдача запроса
об установке тома.

### 9.3. Запрос информации о наличии тома

`ИР 050 А`, где АИСП = 110(8).

Экстракод позволяет узнать, стоит ли на одном из запоминающих устройств ЭВМ
данный том МЛ(МД).

Перед обращением к экстракоду в 1-16 Р СМ записывается номер тома МЛ(МД) в
двоично-десятичном виде.

Выходная информация:

```
СМ=0-Нужный том установлен;
```

=== СИСПРОГ 8.4.1 ДАЙ АРХ / НЕТ АРХ ===
### 8.4. Управление работой архивной системы

#### 8.4.1. Директивы `ДАЙ АРХ` и `НЕТ АРХ`

В том случае, когда была выполнена директива `НЕТ АРХ`, работа архивной
системы блокируется. На операторский терминал выдается ответ `ЕСТЬ`. По
второму маршруту (логическому каналу) периодически выдается `АРХИВ ЖДЕТ`.
В этом режиме на директиву `РЕЖ` сообщается `АРХИВ ОТКЛ.`. Отмена режима
выполняется директивой `ДАЙ АРХ`.
