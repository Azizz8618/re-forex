# 40 — P7c / воспроизведение зависания в simh на копиях: PC и трасса

**Дата:** 20.11.2026. **Режим:** всё сделано в `/var/tmp/p7c-hang/**` на копиях.
Эталоны (`~/.besm6/2348`, `/usr/local/share/besm6/2348`, диски `simh/BESM6/{MD,MB,ML}`),
`src/`, `tests/` ре-forex, процессы `1523201/1523202/1533999` и tmux-сессия `0` не трогались.

## 0. ВЕРДИКТ

**Зависание воспроизводится на копиях, но это не бесконечный цикл в нашем коде, а
спин-ожидание планировщика ДИСПАК.** Машина крутится в двух вложенных циклах ОС:

* **основной цикл: `066642`–`066643`** (51 627 попаданий за 3 с),
  `сч 72266(2)` / `сбр 73424` / `зп 72266(2)` / `цикл 66642(2)`;
* внутренний: `066645`–`066647` (11 040 попаданий за 3 с),
  `сч 3171` / `зп 3170` / `сч 3051` / `зп 3050` / `цикл 66645`.

`Ctrl+G` останавливает машину именно на `СчАС 066643` (`-> зп 72266(2), цикл 66642(2)`),
` ex REG PC` = `066643`, `RK = 01203424`.

**Причина — колода/паспорт задания:** `p7ct.txt~:5` содержит `дис 45(2048)^`, а на
канале `md45` смонтирован том **2348** (`OSZAGR/dispak.ini:46`). Задача принята
(`B075-1 410300000000`), но планировщик не может выбрать её в решение и ждёт
несуществующий носитель, крутясь на сравнии флага. Косвенные улики (PERSO-зоны,
Э70, `physobm`) в этом прогоне **не являются причиной**: до трансляции Fortran
дело не доходит, `ZF*` не вызывались.

PC `04440` (`цикл 4440(15)`), который фигурировал в более ранних логах — это
штатный цикл приглашения `CM1П:`, то есть свободная машина. Он НЕ является
циклом зависания: в воспроизведении с принятой задачей PC = `066642/066643`.

**FS8 не висит.** Колода прочитана (`B075-1` напечатано). Прерывания, которые
машина обслуживает в цикле, — **таймерные** (`GRP` word1 `1400 → 1410`, бит 39 =
`GRP_TIMER` из `besm6_defs.h:480`), 710 прерываний за 3 с; битов `GRP_FS1_SYNC`/
`GRP_FS2_SYNC` (42/41) в `GRP` нет.

## 1. Что готовилось

* `/var/tmp/p7c-hang/setup.py` — копирует 28 дисков/барабанов/МЛ (314 МиБ),
  `boot_dispak.b6` и колоду; переписывает `dispak.ini` на абсолютные пути копий,
  `prn0/prn1` → `/var/tmp/p7c-hang/acpu/`, отключает `tty2..tty24` (порты 4199–4223
  заняты живым процессом `1523202`).
* `/var/tmp/p7c-hang/drive.py`, `drive_trace.py` — покадровый драйвер: загрузка →
  `НОМ` → `ДАЙ А0/A1` → `НОМ/ВЦП` → `Ctrl+G` → `at vu0 …` → `d 6 1`, `d 5 10`,
  `set cpu req`, `go` → контроль `B075` → `Ctrl+G` → дамп регистров →
  `set debug …; set cpu debug; go` (MTR-подобная покадровая трасса в simh).
  Из-за внешнего cleanup-default-tmux-сервера прогоны переведены на изолированный
  сокет `TMUX_TMPDIR=/var/tmp/p7c-hang/tmux`.
* Важно: бинарник `/home/azizz/Yandex.Disk/simh/BIN/besm6` **не содержит** код
  `BESM6_DD_DEBUG` / `BESM6_MTR_*` / `BESM6_CORE_ON_PC` (проверено `strings`: нет
  `MTR %05o`, `CORE DUMPED`; это более новая исходная ветка в `dispak/dispak/cu.c`).
  Поэтому покадровая трасса снята через штатный `set cpu debug` + `set debug <file>`,
  а не через переменные окружения.

То есть rc=1 / таймаут на копиях воспроизводится (90 с без `КОНЕЦ ЗАДАЧИ`), а
устранение именно паспортной заявки `2048 → 2348` убирает цикл. Подмена имени
файла на `2048` не помогает: внутри образа по-прежнему метка 2348.

## 4. Кто виноват

1. **Не Fortran-мост / PERSO / lowering.** `B075-1` печатается до трансляции;
   `ZFOPEN/ZFWRIT/…` не исполнялись. Первая причина лежит выше — в паспорте.
2. **Не драйвер FS8 и не SIMH-мост.** `at vu0` + FS8 отработали: колода прочитана,
   задача принята. Регулярные прерывания — таймер, не FS.
3. **Не «машина крутится в мусоре».** Все PC цикла лежат в коде ОС (`0666xx`,
   `075xxx`), трасса полностью осмысленная.
4. **Причина: рассогласование паспорта и конфигурации** — `дис 45(2048)^` при
   `md45 = 2348`. Планировщик ждёт бобину 2048 (`НЕТ Б 2048`,
   `Dispak-operator-guide.md §8.1.10 / 5.32`) и spin-циклится на `066642/066643`.

Оговорка: прямого `СКВ 075` с причиной на зависшей копии снять не удалось —
поток `physobm`-сообщений рвал ввод операторской директивы (`ДАЙ`/`СКВ`
иногда приходили искажёнными: `ECT8`, `#А1 … ОШИБ`). Причинность доказан
чистым экспериментом с заменой одной строки паспорта и PC-трассой.
