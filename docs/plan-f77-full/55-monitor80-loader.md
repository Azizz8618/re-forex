## 2. Точный путь `*CALL NAME`

1. `star%.masm:373`: карта `*CALL` → `GIV76`.
2. `star%.masm:244-248`: `SAVBLIS1` → `GIVCALL*` →-error check → `CHECKMORE`.
3. `givcall%.asm:23-33`: `IDENT6` превращает текст карты в 6-символьное имя в `MONCARD*+1`; `MAIN*` = адрес входа.
4. `givcall%.asm:35-43` (общий путь `call:`):
   ```
   XTA 73B ; ATX RRR1 ; ASN 64-6 ; AOX п2 ; ATX 73B
   XTS card ; VJM LOADANGO
   ```
   то есть в ячейку `73B` (список LIBRARY) OR-ится бит `п2=LOG,2`, который ставит `*STAND` (`star%.masm:121-129,319-321`).
5. `givcall%.asm:38-41` — **Pascal-only** ветка: при совпадении карты с `*PASCAL` вызывается `MONITOR*+4`, затем `LOADANGO`.
6. `loadango.asm:9-59`: `LNGO` сохраняет `17B`, проверяет «уже в памяти» (`INMEM`), иначе `*70 46B`, `*70 61B`, `WTC 43B`, `VJM 2`; возврат через `RETN` (восстановление `16B/17B`, `STI M13`).

## 3. Каталог PERSO и требование head-модуля

- `libdrum.asm`: `NEWCAT/OLDCAT` — PC 2048 (каталог 2 зоны по 1024 слова); `LWW=NCL+64`, `SAV=NCL+65`, `SAV1=NCL+67` — служебные ячейки.
- `libdrum.asm:122-192`: проверка нового каталога → объединение каталогов (`:225`) → запись имён (`:250`).
- `libdrum.asm:452,510-517`: ошибки `ИСПОРЧЕНЫ ПОДПРОГРАММЫ:`, `ИСПОРЧЕН КАТАЛОГ TEMPORARY/PERSONA/COMMON`, `ПЕРЕПОЛНЕН КАТАЛОГ BPEME...`.
- Опыт M0 (субагент, 20.11.2026): **`*CALL` исполняет только головной модуль каталога** (запись с `f2=0o42xx`, `f3=0o2010`); остальные записи при попытке `*CALL` дают `ИСПОРЧЕНА ПОДПРОГРАММА`. Это объясняет, почему `FOREX*` после перестановки в первую зону стал загружаться, а `FXBANNER` — нет.

## 4. Формат записи каталога и sym-элемента

По `docs/15-perso-build.md:41-49`, `re-siprod/notes/loader.md:1-6`, `pascal-re/format.md:49-84`:

- запись каталога (48 бит): `f3 = off + 0o2010`, `f2 = 0o4000 + zone*0o100 + L/512`, `f1 = (L%512)*8`, `f0 = overlay/entry`; `L = cmd + const + bss` (ПАМ = bss, не data).
- sym-элемент: `(0o4000+X)<<24 | C<<12 | D`; `C=0` — свой символ, `C=0o670/470` — LC/COMMON, `C=0o630` — SUBP постоянной библиотеки.
- **Новую запись нельзя вставлять в начало каталога** (`re-siprod/notes/loader.md:4`): это сдвигает номера входов, на которые ссылаются sym-элементы всех модулей.

## 5. Сообщения об ошибках

- `libdrum.asm:510-517` — ошибки каталога PERSO (подробнее выше).
- `besml21/loader.txt:1235-1242` — тексты загрузчика Дубны: `TERR0..TERR7`, включая `TERR6 = ИСПОРЧЕНА ПОДПРОГРАММА`; `ERROR` (`:1158-1215`) печатает текст + `NAME` + `NAME2`.
- Текущая ошибка `*CALL FOREX*` — `ИСПОРЧЕНА ПОДПРОГРАММА OCTTDE* 03777`: это TERR6 при загрузке не-головного модуля `OCTTDE*`; субагент разбирает отдельно.

## 6. Что это меняет для плана

1. M0 доказательства модульного пути достигнут: отдельный образ с одним модулем `FXBANNER` в зоне `0o2400`, `*perso:602400` + `*call fxbanner` печатает маркер через проверенный `*64` E64 GOST-вывод и возвращается `13,UJ,.`.
2. Для FOREX каждый внешний модуль, который root дёргает через LINK-ячейки, должен либо быть головным (невозможно — головной уже FOREX*), либо разрешаться через системную постоянную библиотеку. Поэтому principal path — **M2: свой загрузчик оверлеев вместо `LOADANGO`**, а не попытка грузить все модули через `*CALL`.
3. `*STAND` — общий бит режима загрузки, но он не превращает не-головной модуль в грузимый; роль PASCOMPL-ветки в `givcall%.asm:38-41` специфична для `*PASCAL`.
