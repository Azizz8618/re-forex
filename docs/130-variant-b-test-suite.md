# Вариант Б: system test suite для автономного Fortran‑компилятора

Набор тестов и инфраструктура прогона находятся в репозитории:

- `tools/forex500-final/` — сборщики и SIMH‑драйверы (`drive_b.py`, `setup_b.py`, `run_suite_full.py`);
- `tests/plan-f77/91-variant-b-final/` — декы с **настоящим Fortran‑текстом** (без `777005`, без `*FOREX`), манифест SHA.

## Контракт прогона

- Образ для `md41` — копия рабочего образа контура; live‑диски не используются.
- SIMH: изолированный tmux‑сокет, boot‑маркер `ДATA:` через `capture-pane`,
  ввод только `send-keys`, stock `attach -n prn0/prn1` с локальным capture‑путь,
  `ДАЙ А0`/`ДАЙ А1`/`НОМВ` до дека, post‑deck `НОМВ` только после подтверждённой
  строки запуска задачи.
- Авторитетный observable — изолированный `prn0` capture; `АЦПУ`‑копии общие
  и могут быть stale.
- Каждый кейс требует `plumbing PASS`, `product_gate PASS`, строку `21 ...`
  (кроме негативного контроля) и `КОНЕЦ ЗАДАЧИ`.
- Текущий бинарь SIMH `d0583057…` (пересобирался параллельно; более старый
  `9ef71b26…` исчез).
