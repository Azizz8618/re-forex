## 3. Address reachability (12-bit ADR vs modifier)

Decode from the SIMH C source (copied read-only):

| fact | file:line |
|:--|:--|
| short instruction: 12-bit ADR; `BBIT(19)` adds `0o70000`; long: 15-bit ADR (`0o77777`) | `simh/BESM6/besm6_cpu.c:1054-1064` (`BBIT(n)=1<<(n-1)` in `besm6_defs.h:86`) |
| `if (RUU & RUU_MOD_RK) addr = ADDR(addr + M[MOD]); next_mod = 0;` | `besm6_cpu.c:1098-1102` |
| `UTC` sets `next_mod = addr + M[reg]` | `besm6_cpu.c:1556-1559` |
| long opcodes exist for `UTC` (0o220), `UJ` (0o300), `VJM` (0o310) only — arithmetic remains short | `besm6_cpu.c:1339,1556,1634,1651` and `besm6_cpu.c:1098` switch |

Therefore `UTC 20000` followed immediately by short `ARX 1637` addresses
`0o20000 + 0o1637 = 0o21637` = N+2 word 0. The modifier is consumed by that
one instruction (`next_mod = 0`), so the following `ATX 2007` and `*64 2004`
are unaffected. Raw MTR confirms this (§7). No new mechanism was invented:
this is the `utc 30000`/`arx` high-RAM technique of docs/65:74-95, docs/89:119-121.

## 8. WRITE proof

A second one-word substitution writes the accumulator into the same N+2 cell:
`z3[51] = 0o0222000000001637` = `UTC 20000 / ATX 1637`
(image `2048_C1_WRITE_MIN`, SHA `c672ad9caab9b46cc3f381a025e00f1139b4868436fc…`).
With the **byte-identical image**, only the deck literal changes
(`1234` -> `5678`; deck SHAs `388e6da3…` / `3fb59748…`):

```
oracle/WRITE_D1234: MTR 30177R atx 21637(0) AU=0000000000004  M20=20000
oracle/WRITE_D5678: MTR 30177R atx 21637(0) AU=0000000000010  M20=20000
```

The value written into RAM `0o21637` (N+2 word 0) is deck-supplied and changes
`4 -> 8` with the deck, while the image is byte-identical. Both runs reached
`КОНЕЦ ЗАДАЧИ`. Reading that same cell back through the §5 patch is the
experiment of §6, so both directions are proven on the same cell and address.
(A single image that writes, reads back and prints in one run was not assembled:
it needs 7 halfwords between `VJM` and `UJ 0(15)`, while only 6 are available
before the shared `floor_int` subroutine at `0o30202`; an attempt clobbered that
subroutine and is not counted as evidence.)
