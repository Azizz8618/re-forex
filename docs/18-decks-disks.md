# 18. Диски в деках `tests/`: тестовые vs боевые, и когда нужен `-wr`

Дата: 2026-11-19. Репозиторий: `re-forex`, ветка `main`.
Требования пользователя:

1. «в тестовых колодах пускай останутся оба диска. В боевых — только 2348»;
2. «лен 60(2348-wr) — wr нужно только если мы что-то записываем».

Продолжение темы: `docs/17-disks-2048-2348.md` (роль дисков и эмуляции),
`docs/14-perso-write.md` (механика записи в PERSO). Здесь — только раскладка
лен-карт по декам `tests/` и режим `-wr`.

## 1. Рабочие определения

| Категория | Признак | Требуемые лен-карты |
|---|---|---|
| **Тестовая колода** | дек, где воспроизводится/сравнивается эталон 2.02, пробы E1, кросс-сверка с `*FTN`, suite-кейс | **обе**: `лен 41(2048)^` **и** `лен 60(2348[-wr])^` |
| **Боевая колода** | дек реально запускает нашу реконструкцию `FOREX 5.00 / 19.11.2026` из PERSO зоны `0o2300` рабочей копии 2348 | **только** `лен 60(2348[-wr])^`, никакого `лен 41(2048)` |

Важное уточнение из `docs/17` §4: «только 2348» относится **к картам в деке**.
Файл `2048` обязан оставаться в `BESM6_PATH` — иначе dispak падает с
`disk_open: no 2048 image found`. Все боевые скрипты и так передают
`BESM6_PATH="$WORK:/usr/local/share/besm6"`, поэтому удаление карты из дека
безопасно.

### 1.1. Когда ставится `-wr`

`docs/14-perso-write.md` §1.3: запись идёт **только при `лен …(2348-wr)`**;
без `-wr` том доступен на чтение. Следовательно `-wr` нужен **только в той
колоде, где есть команда записи на диск**:

| Признак записи | Пример |
|---|---|
| `*to perso:LUZZZZ` | `*to perso:602310`, `*to perso:402300` |
| `*to perso:LUZZZZ,CONT` (дозапись) | `*to perso:602310,cont` |
| `*W:` / `*write` | — |
| `*copy … -WR` | — |
| `*keep` при записи | — |

Простое монтирование `*perso:602300` **не является записью** — это загрузка
уже существующей библиотеки из зоны `0o2300` на чтение. Команды `*forex`,
`*execute`, `*ftn`, `*punch`, `*call`, Fortran `WRITE(…)` в программе, а также
`дис 40(2348)` / `disc:41(2048)/system,lcross` **к записи на 2348 не
относятся**: `-wr` для них избыточен.

Итог правила:

- колода **только компилирует/исполняет** → `лен 60(2348)^`;
- колода **пишет библиотеку** (`*to perso`) → `лен 60(2348-wr)^`.
