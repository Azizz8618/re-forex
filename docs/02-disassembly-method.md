# Метод дизассемблирования оверлеев ФОРЭКС

## Проблема с `disbesm6`

`disbesm6 -a0 -e0 build/LO_SYN.words` выдаёт корректный код только для первых
23 слов (0..22), после чего встречает `пб START` и объявляет остаток зоны
данными: 1005 строк `конд` из 1024. На самом деле слова 23..1777 — executable
код (см. `besm6tape.py dis`: `2367555130445501 → *36 75551(4),mtj 5501(6)`).

**Вывод:** `disbesm6` непригоден как единственный источник для этих оверлеев.

## Рабочий метод

1. Извлечь зону: `tools/extract_words.py --start 241500` (или `dd bs=6`).
2. Полный листинг с русскими мнемониками:
   ```bash
   python3 ~/Yandex.Disk/besm6-new/besm6.net/tools/besm6tape.py dis \
     ~/Yandex.Disk/besm6-new/besm6.net/tapes/monsys.9 \
     --start 0o241500 --count 1024 --bemsh > disasm/LO_SYN.bemsh.lst
   ```
3. Тот же листинг латинскими мнемониками (`--bemsh` убрать) — для сверки.
4. `disasm/*.raw.lst` (disbesm6) использовать только для первых 23 слов.
5. Автоматический сбор переходов: `tools/xref_scan.py disasm/LO_SYN.bemsh.lst`.
6. Декодирование TEXT-констант: `tools/extract_words.py --decode-text`
   (8 шестибитных символов/слово, код = ASCII − 0x20).

## Дизассемблирование в МАДЛЕН через dtran

По образцу `re-siprod/tools/siprod_madlen.py` (`dtran -F dms <module>` даёт
настоящий МАДЛЕН-текст, пример `re-siprod/madlen-gen/ADRSEK.madlen`) сделан
`tools/dtran_wrap.py`: сырая зона оборачивается в синтетический DMS-модуль
(распакованный заголовок из 3 слов, тело как секция команд, имя и расширенная
таблица символов на 0o7777 записей — без неё dtran падает с SIGSEGV):

```bash
tools/dtran_wrap.py build/LO_SYN.words --out disasm/LO_SYN.dtran.madlen
tools/dtran_wrap.py build/LO_GEN.words --out disasm/LO_GEN.dtran.madlen
```

Результат — 6150 / 6000 строк МАДЛЕН (`LO*SYN  :,NAME, NEW DTRAN`, mnemonics
`XTA/ATX/VTM/VJM/A+X/...`). Часть операндов равна `dunno` (синтетическая
симтаблица), поэтому явные адреса и значения берутся из `*.bemsh.lst`.
Итоговый аннотированный текст — `src/LO_*.mad`.

## Структура оверлея

| Слово | Содержимое |
|---|---|
| 0 | маркер модуля `0o200003` |
| 1 | имя в MADLEN TEXT: `LO*SYN` / `LO*GEN` |
| 2..22 | стартовый код (проверки, настройка M14–M16, вызов `пв 20116(15)`) |
| 23..1777 | основная процедура и таблицы констант |

Адреса в листинге — абсолютные слова ленты. Относительный адрес =
абсолютный − `0o241500` (SYN) или − `0o277500` (GEN).

## Переходы вовне

Сканер нашёл 215 управляющих команд в SYN и 395 в GEN. Большинство целей —
абсолютные адреса резидентной памяти `0o20000..0o77777`
(например `42440`, `40440`, `20103`, `77144`, `57476`), а не адреса внутри
оверлея (загружаемого по `0o22654`). Это вызовы процедур корня `FOREX*`,
библиотеки DECODER и MONSYS. Они сводятся в `docs/03-symbols.md`.
