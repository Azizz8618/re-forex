# GOTO / arithmetic IF из Fortran‑текста: авторитетная SIMH‑проверка

B7 сначала был `BLOCKED` (`docs/136`) по двум причинам: дефекты machine‑кода
в label fix‑up и SIMH port contention. Обе устранены.

## Исправленные machine‑дефекты (из C‑oracle MTR)

1. 12‑битный ADR обрезал базу N+2 при извлечении байта метки:
   `asx 1642(0)` заменён на `UTC + reg11` indexed form.
2. Тест цифры ветвил в `LABEL_BAD` на корректных цифрах.
3. `IFL_DONE` / `GL_DONE` вызывали `a.d()` с body‑индексами, из‑за чего
   `PATCHTOK` правил token index 0 вместо реального токена GOTO/IF.
4. `FIX2_IF` использовал left‑shift control там, где нужен `ASX` right shift
   для выделения поля PAY.
