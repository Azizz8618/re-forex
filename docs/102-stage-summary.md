## 3. Не доказано / невозможно

- **DSQRT**: нет double FPU, софтверная DP >100 команд; зона `N+4` недоступна
  (`docs/101`, дескриптор `0o400402757101760` — единственный рабочий).
- **Дескрипторный `READ(u,fmt)`**: `э52` векторится в `0o0552`, бит привилегии
  задачи = 0 (`docs/91/92`); работает только буквальный ввод из буфера карты.
- **Полная компиляция**: декодируется только ведущая цифра LIT ×100;
  `777001..777004` не парсятся, `777010/777011` в репозитории отсутствуют.
- **FT*002/003**: страницы MMU защищены (`docs/88`); `*50` из контура под SIMH
  аварийно завершается.
- Печать имеет масштаб `/10`; минус из карты не проверен.
- Ранние PASS `docs/83/84/86` использовали питоновски подставленные значения и
  по правилу «всё считается на БЭСМ‑6» приёмкой не являются.

## 4. План

1. Канонический продукт‑контур: свести проверенные куски в один образ и один дек,
   зафиксировать SHA‑манифест.
2. Парсер IR вместо одной цифры: весь LIT с учётом ×100, затем `777001..777004`;
   восстановить эмиттеры `777010/777011`.
3. Числовая корректность: снять масштаб `/10`, проверить минус из карты.
4. Обновить `docs/73` §4 под текущие факты.
5. Зафиксировать границы (DSQRT, `READ(u,fmt)`, защищённые страницы) как лимиты
   изделия или получить решение об их снятии.

Тег `v5.00-forex-f77-contour` не перетирать; финальный release и пуш тега
только по явному разрешению пользователя.
