# План перехода ФОРЭКС к FORTRAN 77

**Цель:** повысить проверяемость реконструкции, сохранив (и где возможно улучшив)
эффективность генерируемой программы.

## Эмпирическая база (получена до планирования)

Пробные компиляции системным ФОРЭКСОМ 2.02 в dispak — `tests/plan-f77/probe.sh`,
лог `logs/plan_f77_probes.txt`:

| Конструкция | Результат |
|---|---|
| `DO 10 I=1,5`, `BLOCK IF/THEN/ELSE/ENDIF` | OK |
| `CHARACTER*10` + подстрока `S(2:4)` | FAIL на 2.02 («ТИП ОП-ДА НЕ СООТВЕТ ОПЕРАЦ»); на 4.13 Dhrystone подтверждён `CHARACTER*30` |
| `DOUBLE PRECISION`, `1.0D0`, `SNGL` | OK |
| `COMPLEX Z; Z=(1.0,2.0)` | OK |
| `DATA N/5/`, `PARAMETER (N=5)` | OK |
| `SQRT`, `ABS`, вызов внешней `FOO`, `LOGICAL` | OK |
| `PRINT *,N` (list-directed) | FAIL «ОШИБКА В ССЫЛКЕ НА ФОРМАТ» |
| `IMPLICIT NONE`, `SAVE` | FAIL «НЕДОПУСТИМ КЛЮЧ СЛОВО» |
| `READ(*,*,END=99)` | FAIL «НЕДОПУСТИМ СИМВОЛ * В ВЫРАЖ» |
| `READ(*,*,END=99)` | FAIL «НЕДОПУСТИМ СИМВОЛ * В ВЫРАЖ» |

Ограничение: это базовые формы на версии 2.02; версия 4.13 (Dhrystone) шире.

## Структура плана

1. `01-gap-analysis.md` — расхождения диалекта с F77, приоритеты по переносимости.
2. `02-extension-points.md` — точки расширения в корне/оверлеях/рантайме; вердикт «Fortran или ассемблер».
3. `03-fortran-path.md` — путь расширений без ассемблера: Fortran-процедуры и source-to-source preprocessing.
4. `04-assembler-path.md` — путь правок МАДЛЕН-текстов, проблема симтаблицы и стратегия проверки.
5. `05-decision.md` — итоговое решение, этапы, критерии приёмки (собирается родительским агентом).

## Критерии, которые необходимо соблюдать

- **Проверяемость:** каждый этап имеет эталонный ввод/вывод, автотест и pinpoint-диагностику; регрессия现有 16 сценариев не ломается.
- **Эффективность:** приоритет inline-генерации в `LO*GEN` для часто используемых конструкций; вызовы внешних Fortran-процедур допустимы для редких/сложных возможностей; накладные расходы preprocessing — только на компиляцию, не на выполнение.
- **Совместимость:** уже работающие программы (Глиссада, Dhrystone, Whetstone, forex.b6) должны компилироваться и давать прежний результат.
