# LO*SYN — использование регистров
Источник: `disasm/LO_SYN.bemsh.lst` (операнды вида `N(Mxx)`), `disasm/LO_SYN.full.lst`, `disasm/LO_SYN.dtran.madlen` (префикс регистра — десятичный номер,bemsh — восьмеричный: `14`↔М12, `15`↔М13, `16`↔М14, `17`↔М15).

Обозначения: См — аккумулятор; M1..M17 — индексные регистры; МОДА/МОД — модификатор адреса (сдвигает адрес следующей команды).
«Предположительно» помечены гипотезы о смысле значения.

## 3. Аккумулятор (См)
Используется как основной регистр данных: принимает значения из ячеек (`XTA`, `XTS`, `ITA`), записывается в память (`ATX`, `APX`), участвует в арифметике (`A+X`, `X-A`, `E-X`, `AMX`, `A+X`), логике (`AAX`, `AOX`, `ACX`, `ASX`) и служит для ветвлений `UZA`/`U1A`. В таблице автомата (слова 1517..1777) первая половина каждого слова — `ATX <код>`, то есть в См загружается код состояния/класса лексемы перед переходом.

## 5. Модификатор адреса (МОДА/МОД / `UTC`, `WTC`)
`UTC`/`WTC` встречены 143 раз; задают смещение, добавляемое к адресу следующей команды. Типичные аргументы: `30312`, `20040(6)`, `40(2)`, `20160(6)`. Это основной механизм адресации таблиц в оверлее.
