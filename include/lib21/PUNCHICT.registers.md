# PUNCHICT — регистры

Использование индексных регистров М1..М17 в модуле `PUNCHICT` (`libra212.l21:11999-12102`). Соглашения — `docs/04-register-conventions.md`.

| Рег. | Упоминаний | Установок (VTM/ATI) | Возвратов (UJ/VJM) | Пример |
|---|---|---|---|---|
| М5 | 5 | 2/0 | 0 | S2:12024 `ITA,5` |
| М6 | 5 | 2/0 | 0 | S2:12026 `ITA,6` |
| М7 | 24 | 2/0 | 0 | S2:12020 `ITS,7` |
| М8 | 3 | 2/0 | 0 | S2:12058 `8,VTM,BUFFER` |
| М9 | 4 | 3/0 | 0 | S2:12056 `9,VTM,77777B` |
| М13 | 4 | 0/0 | 3 | S2:12028 `ITA,13` |

## Роли (по соглашениям `docs/04-register-conventions.md`)

- **М7** — указатель кадра / рабочая база.
- **М13** — linkage/возврат: `13,VJM`, `13,UJ`.

Остальные регистры модулем не используются; их роли — в `docs/04-register-conventions.md`.
