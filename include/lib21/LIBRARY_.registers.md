# LIBRARY_ — регистры

Использование индексных регистров М1..М17 в модуле `LIBRARY/` (`libra212.l21:1496-1631`). Соглашения — `docs/04-register-conventions.md`.

| Рег. | Упоминаний | Установок (VTM/ATI) | Возвратов (UJ/VJM) | Пример |
|---|---|---|---|---|
| М5 | 2 | 2/0 | 0 | S2:1522 `VTM,5` |
| М7 | 2 | 0/0 | 0 | S2:1515 `ITS,7` |
| М8 | 1 | 0/0 | 0 | S2:1622 `8,,` |
| М9 | 2 | 2/0 | 0 | S2:1521 `9,VTM,NLIBI` |
| М10 | 3 | 3/0 | 0 | S2:1518 `10,VTM,` |
| М11 | 8 | 0/0 | 0 | S2:1520 `11,VZM,ERROR` |
| М13 | 10 | 3/0 | 3 | S2:1514 `ITA,13` |
| М14 | 6 | 2/0 | 0 | S2:1510 `14,VTM,21B` |
| М15 | 6 | 0/0 | 0 | S2:1569 `15,ATX,` |

## Роли (по соглашениям `docs/04-register-conventions.md`)

- **М7** — указатель кадра / рабочая база.
- **М10** — адрес блока, второй канал возврата.
- **М13** — linkage/возврат: `13,VJM`, `13,UJ`.
- **М14** — индекс/база таблиц и буферов: `14,VTM`, `14,XTA`, `14,VLM`.
- **М15** — адрес возврата / рабочий счётчик: `VJM ... (15)`.

Остальные регистры модулем не используются; их роли — в `docs/04-register-conventions.md`.

## Обновление имён (этап 12)

Авто-метки (2) и TEXT-константы (0) переименованы: короткие имена ≤6 символов, полные — в `POLN:`; смещения `LABEL+NNNB` → десятичное: 0. Подробности: `LIBRARY_.xref.md`, `logs/labels_semantics_lib21_core.txt`.
