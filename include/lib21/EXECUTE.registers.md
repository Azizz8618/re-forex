# Регистры модуля `EXECUTE` (M1..M17 и аккумулятор)

**Источник:** `libra211.l21:13875-14312`.

Использование индексных регистров и аккумулятора по подпрограммам/секциям.
Обозначения: `A` — аккумулятор, `M1…M17` — индексные регистры;
`зап.` — запись в регистр, `чт.` — чтение регистра, ` mods` — модификация адреса.

## Сводка по регистрам (целевое назначение)

| Регистр | Роль в модуле |
|---|---|
| M9 | индексный регистр/указатель |
| M10 | индексный регистр/указатель |
| M13 | возврат/связь (RET) |
| M14 | база COMMON / индекс таблицы |
| M15 | LINK-ячейка вызова (0o740xx) |
| A | аккумулятор: приём/передача операндов, сравнение, адрес перехода |
