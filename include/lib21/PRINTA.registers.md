# PRINTA — регистры

Использование индексных регистров М1..М17 в модуле `PRINTA` (`libra212.l21:10829-10868`). Соглашения — `docs/04-register-conventions.md`.

| Рег. | Упоминаний | Установок (VTM/ATI) | Возвратов (UJ/VJM) | Пример |
|---|---|---|---|---|
| М2 | 1 | 0/0 | 0 | S2:10863 `2,,` |
| М3 | 1 | 0/0 | 0 | S2:10861 `3,000,4` |
| М8 | 2 | 0/0 | 0 | S2:10862 `8,006,7777B` |
| М10 | 1 | 0/0 | 0 | S2:10865 `10,,` |
| М11 | 1 | 0/0 | 0 | S2:10840 `11,BASE,E` |
| М12 | 1 | 0/0 | 0 | S2:10866 `12,,` |
| М13 | 1 | 0/0 | 1 | S2:10860 `13,UJ,` |
| М14 | 9 | 2/3 | 0 | S2:10831 `ATI,14` |
| М15 | 2 | 0/0 | 0 | S2:10846 `15,ATX,` |

## Роли (по соглашениям `docs/04-register-conventions.md`)

- **М10** — адрес блока, второй канал возврата.
- **М12** — указатель магазина (стека).
- **М13** — linkage/возврат: `13,VJM`, `13,UJ`.
- **М14** — индекс/база таблиц и буферов: `14,VTM`, `14,XTA`, `14,VLM`.
- **М15** — адрес возврата / рабочий счётчик: `VJM ... (15)`.

Остальные регистры модулем не используются; их роли — в `docs/04-register-conventions.md`.
