# FOREX_RUNTIME — register conventions

Наблюдаемое использование индексных registers и linkage в модулях
`FORMAT`, `FORTLIBR`, `DATAPR*`, `OCTTDEC`. Дополняет
`docs/04-register-conventions.md` и `include/FOREX_ROOT.mad:137-149`.

Обозначения: **S1** = `libra211.l21`, **S5** = `besmmons/system1.txt`,
**S6** = `besmmons/system2.txt`, **S7** = `besmtask/exfor.vv`,
**S2** = лента `monsys.9`.

## 1. Сводная таблица

| Рег. | Модуль | Роль | Свидетельство | Уверенность |
|---|---|---|---|---|
| M7 | FORTLIBR / PRINT8 | рабочий: база констант `*00061`, приём `XTS *00064`, запись `*00100` | S1:15596,15598-15600 | высокая (прямо из текста) |
| M12 | FORMAT | база таблицы передач `77766B`, счётчик цикла `VLM` | S1:15549,15552,15555 | высокая |
| M13 | DATAPR* | база `DARET` (`BASE DARET`), возврат `13,UJ,.` | S5:7653,7659 | высокая |
| M13 | OCTTDEC (S6) | возврат `13,UJ,` | S6:5068 | высокая |
| M13 | FORTLIBR / PRINT8 | linkage: `13,VJM WRITLIBR+1`, `13,VJM PRINT8`, `13,UJ,` | S1:15603,15615,15608 | высокая |
| M14 | FORMAT | индекс таблицы: `ATI 14`, `14,XTA`, `14,UTM`, `14,VZM` | S1:15541-15554 | высокая |
| M14 | FORTLIBR / PRINT8 | база констант `*00061`, `*00014`, буфера `BUFFER` | S1:15594,15601,15620 | высокая |
| M14 | OCTTDEC (S7) | база модуля `14,BASE,*` | S7:428 | высокая |
| M14 | DATAPR* | индекс названия месяца: `VTM 24`, `ASN 64` | S5:7671,7676 | средняя |
| M15 | OCTTDEC (S7, EXFOR) | указатель стека / возврат: `UTM -2`, `WTC 1`, `UJ` | S7:447,452,453 | высокая |
| MOD | FORMAT, FORTLIBR | модификатор адреса: `WTC *00026`, `WTC *00077` | S1:15552,15635,15645,15653 | высокая |

## 2. По модулям

### 2.1 FORMAT (S1:15529-15589)

```
M14 <- acc          ; ,ATI,14      (S1:15541)
acc <- (M14)        ; 14,XTA,      (S1:15542)
M12 <- 77766B       ; 12,VTM,77766B (S1:15549)  — база таблицы передач
MOD <- *00026       ; 12,WTC,*00026 (S1:15552)
цикл: 14,UTM / 14,VZM *00012 / 12,VLM *00005 (S1:15553-15555)
STX, ATI 14         ; запись и продвижение указателя (S1:15561-15562)
```

Индекс M14 перебирает 11 пар `UJ FT*nnn / ATX 77xxxB`; M12 задаёт базу
таблицы, модификатор `WTC` используется для адресации её элементов.
См. `include/FOREX_RUNTIME.xref.md` §4 и скомпилированный вид на ленте
S2:0o510443-0o510522.

### 2.2 FORTLIBR / PRINT8, WRITLIBR (S1:15590-15712)

```
14,VTM,*00061       ; M14 = база констант PRINT8
ITA 7 / ITS 13      ; M7 = рабочий, M13 сохраняет linkage  (S1:15596-15597)
7,VTM,*00061        ; M7 = база констант
13,VJM,WRITLIBR+1   ; linkage через M13                    (S1:15603)
STI / STI 13 / STI 7 ; сохранение регистров в стеке         (S1:15605-15607)
13,UJ               ; возврат через M13                    (S1:15608)
13,VJM,PRINT8       ; повторный вызов PRINT8               (S1:15615)
14,VTM,BUFFER       ; M14 = адрес буфера 0o2000 слов       (S1:15620)
WTC,*00077          ; модификатор адреса                   (S1:15635 / 15645 / 15653)
```

Отличительная черта PRINT8 — linkage через **M13**, а не через M15
(ср. с корнем, где `CALL` компилируется в `vjm ... (15)`,
`include/FOREX_ROOT.mad:143-144`).

### 2.3 DATAPR* (S5:7645-7733)

```
ITS,13              ; сохранить M13                        (S5:7652)
13,BASE,DARET       ; M13 = база констант/тайтлов          (S5:7653)
13,UJ,.             ; возврат через M13                    (S5:7659)
15,XTS,-2/-3/-4/-8  ; M15 — смещения при разборе FUN 67B   (S5:7662-7688)
14,VTM,24           ; M14 — счётчик/индекс месяца          (S5:7671)
PRINT               ; вывод строки                        (S5:7693)
STI,13 / 13,UJ      ; восстановление и возврат             (S5:7696-7697)
PREPDAT: ITS,13 / 13,VJM,DATE* / UJ,DATAPR* (S5:7699-7711)
```

Внутренний вызов `PREPDAT → DATE*` использует M13 как linkage, затем
`DATE*` возвращается в `PREPDAT`, который передаёт управление главной
точке входа `DATAPR*`.

### 2.4 OCTTDEC — реализация DECODER (S6:5042-5084)

```
12,VTM,C            ; M12 = база C (module base)            (S6:5044)
12,STX,DEC-C        ; DEC по базе C                        (S6:5046)
14,VTM,-5           ; M14 = -5 (счётчик цифр, 6 шагов)      (S6:5050)
14,UTC,C1 / 14,VLM,/6SYMB ; проход по REAL 100000.0 … 1.0  (S6:5053,5065)
15,ATX,             ; M15 — запись промежуточной цифры      (S6:5057)
13,UJ               ; возврат через M13                    (S6:5068)
```

### 2.5 OCTTDEC — вариант EXFOR (S7:427-459)

```
14,BASE,*           ; M14 = база модуля                    (S7:428)
ITS,13              ; сохранить M13                        (S7:430)
13,VTM,             ; M13 = рабочий счётчик (уменьшается на 4) (S7:431,440)
15,XTS,-3 / 15,ATX,-3 ; M15 = указатель на разряд          (S7:434-436)
15,UTM,-2 / 15,WTC,1 / UJ ; возврат через M15 как стек      (S7:447,452,453)
```

## 3. Отличия от соглашений корня

| | Корень `FOREX*` (S2:0o510300+) | Рантайм-модули |
|---|---|---|
| Linkage CALL | `vjm ... (15)` — M15 | PRINT8/DATAPR*/OCTTDEC(S6): M13; OCTTDEC(S7): M15-стек |
| База констант | M13 (`13,VTM,TTEX`), M14 (`14,VTM,ENTRY*`) | M12 (FORMAT), M14 (PRINT8/OCTTDEC S7), M13 (DATAPR*) |
| Модификатор | `WTC RET.` (S1:15508) | `WTC *00026` / `*00077` (S1:15552,15635) |

Это ожидаемо: модули собирались раздельно (библиотека 21, MONSYS, EXFOR),
единого соглашения на M15 нет.

## 4. Неясности

1. `INT0:,INT,0` (S6:5075) участвует в формировании ISO-кода цифры, но
   является ли это кодом `'0'` (0o60) — требует проверки числового
   значения после трансляции. `ZERO = 8TEXT «000000»` (S6:5083) — более
   надёжный кандидат на роль «добавить 0o60 к каждой цифре».
2. Точная роль M15 в DATAPR* (`15,XTS,-2` и т.д.) — разбор результата
   `FUN 67B`, интерпретация смещений {-2,-3,-4,-8} проверена только по
   тексту, без трассы.
3. Для OCTTDEC (S6) не ясно, почему счётчик инициализуется `-5` при
   шести цифрах — возможен дополнительный шаг в начале цикла.
4. Физические адреса 0o77xxx в оверлеях не сопоставлены с этими
   регистрами: нужна карта загрузки MONSYS.
