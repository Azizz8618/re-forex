# RUNTIME_DISASM — таблица регистров (дизассемблированные FORMAT / FORTLIBR)

Источник: машинный код ленты `monsys.9` (`0o510443-0o510537`,
`0o510543-0o510647`), сверен с `reference/libra211.format.inc`.
В дизассемблере `besm6tape.py` номер регистра печатается в восьмеричном;
здесь указан и машинный номер, и номер МАДЛЕН-исходника.

| Регистр | Модуль | Роль в машине | Ссылки (лента / S1) |
|---|---|---|---|
| M7  (oct 7)  | FORTLIBR | рабочий указатель полей буфера; `VTM *00061`, `XTS/ATX *00064/*00100` | `0o510545, 0o510547, 0o510602 …` / S1:15596,15598,15599,15600 |
| M12 (oct 14) | FORMAT | база таблицы передач `77766B`; счётчик цикла `VLM` | `0o510447, 0o510452` / S1:15549,15552,15555 |
| M13 (oct 15) | FORTLIBR | регистр связывания PRINT8/WRITLIBR (`VJM`, `UJ`, `STI`) | `0o510547, 0o510552, 0o510555` / S1:15597,15603,15608,15615 |
| M14 (oct 16) | FORMAT | индекс таблицы (`ATI`, `UTM`, `VZM`); FORTLIBR: база констант и `BUFFER` | `0o510443, 0o510450, 0o510543, 0o510560` / S1:15541,15548,15553,15554; 15594,15620 |
| M15 (oct 17) | FORTLIBR | экстракод `*70`, сдвиг `ASN 54B`, `AOX` при сборке ISO-слова | `0o510621, 0o510622` / S1:15685-15688 |
| Модификатор адреса (WTC) | FORMAT / FORTLIBR | адресация ячеек `*00026`, `*00077`, `*00072` | `0o510450` / S1:15552; `0o510570, 0o510601, 0o510614` / S1:15635,15645,15653,15676 |

## Регистры по подпрограммам

### FORMAT (`0o510443`)
- M14 — указатель на текущий дескриптор формата; декрементится `UTM`, проверяется `VZM`.
- M12 — база таблицы `FTBTAB = 0o77766`; цикл `VLM FMT005` обходит 11 записей.
- Аккумулятор A / X — вычисление смещения (`ASN FTADR`, `UTC FTLOG`, `AEX`,
  `ASN FTOFSM`), запись через `STX FMT012`.

### FORTLIBR (`0o510543`)
- PRINT8: M14 := база констант `BAS61 = *00061`; M7 — счётчик/указатель;
  M13 — linkage; вызов `WRITLIBR+1` через `VJM`, затем `VJM PRINT8`.
- WRITLIBR: M14 := `BUFFER` (LINK `0o74001`); M7 — адресация полей буфера
  `*00062 … *00077`; M15 — экстракод `*70` и `ASN 54B`; M13 — возврат.

## Примечание о LINK-ячейках

Ячейки `0o74001-0o74013` в старшем поле ленты — не код и не регистры, а
LINK-заглушки (`yta,ati 15`). Их содержимое подставляется компоновщиком при
загрузке; в дизассемблированном тексте они помечены `X01 … X13`.
