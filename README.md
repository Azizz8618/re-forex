# re-forex — FOREX 5.00 / 19.11.2026 (re-forex)

**Версия изделия: FOREX 5.00 / 19.11.2026 (re-forex).** Реконструкция компилятора
**ФОРЭКС (FOREX) ИПМ АН СССР** для БЭСМ-6.
Компилятор написан на автокоде МАДЛЕН/БЭСМ: корневой модуль `FOREX*` и два
последовательно загружаемых оверлея `LO*SYN` (синтаксис) и `LO*GEN`
(генерация кода). Входной язык — Фортран, близкий к Фортрану‑77.

Оверлеи дизассемблированы и аннотированы; все регрессионные сценарии проходят.
План и разведка носителя — [docs/PLAN.md](docs/PLAN.md), состояние этапов —
[checklist/STATUS.md](checklist/STATUS.md).

## Что уже установлено

- Репозиторий `re-forex` на GitHub был пуст; этот коммит — первый.
- Тела оверлеев найдены на ленте `monsys.9`: `LO*SYN` — зона `0120`, слово
  `0o241500`; `LO*GEN` — зона `0137`, слово `0o277500`.
- Баннер `OVERLAY … FOREX 412` — сервисное сообщение монитора, не код оверлея.
- Исходник корневого модуля `FOREX*` сохранён в библиотеке 21 Дубны
  (`libra211.l21:15448-15528`).
- Пересобранный из текстов `SETTRAN*` печатает наш маркер `21 1.00 3.00`
  при вызове `*TRANS:OURMRK*,,411744` (A/B, `tests/plan-f77/66-newcomp-ourcode/`);
  подробности и граница результата — `docs/61-ttable-newcomp-findings.md` §22.

## Правила

- Эталонные образы и листинги не изменяются; рабочие копии — в `build/`.
- Статус этапа меняется только по факту: побайтовая сверка или документ-результат.
- Каждый найденный символ в листинге снабжается ссылкой `источник:строка`.
- Версии `2.02 от 15.07.80`, `4.13 от 11.09.85` и `FOREX 412` — разные
  сборки; хранятся все три эталона и не смешиваются. **Семантическая база
  реконструкции — FOREX 4.13** (Дубна, исходник корня `libra211.l21:15448-15528`,
  gold `reference/expect_forex.txt`); 2.02 — системный эталон dispak 2048 и
  bootstrap-компилятор этой среды.
- **Наша версия — 5.00.** Баннер `ВЕРСИЯ 2.02 ОТ 15.07.80` в эталонных
  прогонах печатает системный ФОРЭКС диска 2048 (проверено прогоном с
  PERSO-образом и без него). Константы 2.02/4.13 отсутствуют в наших модулях
  (база 4.13 задана исходником корня и gold-эталонами, а не баннером),
  поэтому патч невозможен: системный баннер 2.02 остаётся, а версия изделия —
  FOREX 5.00 / 19.11.2026. Метки `FOREX 5.00` и `19.11.2026` записаны в хвост
  PERSO-образа и в заголовки исходников; подробности — `docs/16-glissade-run.md` §6.
