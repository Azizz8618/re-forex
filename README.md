# re-forex — FOREX 5.00 (изделие на БЭСМ-6)

**Версия изделия: FOREX 5.00.** Реконструкция компилятора **ФОРЭКС (FOREX)
ИПМ АН СССР** для БЭСМ-6. Семантическая база — тексты FOREX 4.13 (Дубна);
системный ФОРЭКС 2.02 диска 2048 используется **только как build‑компилятор**.

## Главное требование и архитектура

- Целевое задание вызывает **только наш транслятор**:
  `*TRANS:FRX5*,,412350` (контур в зоне `0o2350`).
- В целевом деке **нет** `*FOREX`, `*FTN`, `*perso`, F77LIBR и других системных
  компиляторных карт. `*perso` допустим только для вспомогательных программ
  (по образцу `pascal-re`).
- Все значения считаются **на БЭСМ‑6 машино‑кодом**; питоновские подстановки
  в результат запрещены. Ранние «PASS» с host‑folded значениями приёмкой не
  являются (`docs/106` §7).
- В картах пишется том **`2048`**, не `2348` (`docs/80-deck-2048.md`).
- SIMH‑проверки: только копии дисков, маркер `ДATA:`, ввод `send-keys`,
  вывод `capture-pane`, stock `attach -n prn0/prn1`, `ДАЙ А0/A1` + `НОМВ`.
  Актуальный бинарь `BIN/besm6` — `d0583057…` (пересобирался параллельно).

### Что умеет контур

- читать IR‑запись `777005` (FRONT build‑шаг): 4 цифры LIT (`1234` = 12.34)
  и переменные `777005 <seq> 2 0 <VIDX> 0` с таблицей в зоне N+2
  (`docs/104`, `docs/109`);
- вычислять ABS, SQRT, MOD на FPU/BESM‑6 (`docs/95`);
- превращать float в упакованные GOST‑цифры 2+2 со знаком (`docs/89/90/100`);
- печатать через `*64`; SIMH A/B/C: `21 -0012.34` → `21  0012.34` → restore,
  `5678` → `21 -0056.78`, `X` → `21 -0078.90`.

**Интегрированный вариант C7** (`docs/116`, отдельный продукт): один контур
40/58 слов N+3 + 177/649 N+2, общий сканер и dispatch, 6 IR‑записей в деке дают
6 machine‑вычисленных печатей (LIT, VARIABLE, `*`, SQRT, ширина, DO); SIMH
A/B/PATCH/RESTORE PASS. Сборка — `tools/forex500-c7/`, дек — `tests/plan-f77/90-c7-integrate/`.

**Вариант Б (цель пользователя: Fortran‑текст в целевом деке, без IR и FRONT):**

- `docs/121` —machine‑лексер читает `X=12.34` из Fortran‑карты и печатает;
- `docs/124` — `X=1.5+2.5*4.0` → `11.50`, скобки → `16.00`;
- `docs/125` — `PRINT 100,X` + `100 FORMAT(1X,F4.2)` из текста;
- `docs/126` — `DO 10 I=1,2` / `10 CONTINUE` из текста;
- `docs/127`, `docs/129` — SQRT и ABS по имени из текста (ABS: причина `КОНТРОЛЬ КОМАНДЫ` — переход N+2 499→901 через запретную зону; исправлено);
- `docs/128` — финальный интегрированный образ `b9bfba21…` (55/58 N+3, 518/649 N+2): 14 SIMH‑кейсов, 9/9 позитив + негатив + PATCH/RESTORE PASS; T5 DO в этот образ не вошёл.
- Сборки: `tools/forex500-final/`, дек и тесты `tests/plan-f77/91-variant-b-final/`.
- В работе: объединение DO+ABS в один образ (`b-final-do`) и `MOD(X,Y)` по имени.

Бюджет: **45/58 слов** зоны `N+3` с переменными (13 слов резерва). Зона N+2
имеет RAM‑базу `0o21637`; офсеты `0..525` и `901..1023` свободны, `526..900`
заняты обязательной таблицей оверлея. 58 слов — жёсткий предел загрузчика
(`docs/101`).

### Тестовое задание (полный текст дека)

```
ШИФР 410300 ЗС5^
ДИС 41(2048)^
ОЗУ 32^АЦП 32^
ЕЕВ1А3
*NAME FRX5XX
*TRANS:FRX5*,,412350
      PROGRAM MAIN
  777005       6       1       0    1234       0
      END
*EXECUTE
*END FILE
``````
ЕКОНЕЦ
```

`*NAME` обязан быть **6 знаков** (`FRX5XX`); 4‑значное `FRX5` сдвигает
fixed‑offset чтение IR‑карты и даёт `ПЕРЕПОЛНЕНИЕ АУ` (`docs/108`).

## Ограничения изделия

Полный список с доказательствами — [docs/106-final-limits.md](docs/106-final-limits.md)
(ревизия от 24.11.2026): DSQRT — **ограниченно реализован** (`docs/141`:
двухсловная точность ACC+RMR, `hi+lo` для `2.0D0` совпадает с IEEE double
на 20 цифрах; печать `F4.2`, `D`‑экспонента без знака, произвольные
DP‑литералы — открытые задачи); дескрипторный `READ(u,fmt)` (привилегированный
`э52`) — невозможен, но **машинный READ из data‑карты** буфера `0o64000+`
доказан (`docs/140`); FT*002/003 (MMU), `*50` (авария под SIMH) — недоступны;
`777001..777004` и эмиттеры `777010/777011` не разобраны. Массивы (`docs/133`
§4) — открытая задача D3, прерванная лимитом тарифа субагента.

## Исторический материал (не приёмка)

- Оверлеи `LO*SYN`/`LO*GEN` дизассемблированы и аннотированы (1024/1024 слов);
  корень `FOREX*` (96 слов), рантайм `FORMAT`/`FORTLIBR`/`DATAPR*`/`OCTTDEC`.
- Тесты 66..86 и матрица 200/200 доказывали системный путь и/или значения,
  подставленные хостом; они остаются разведкой, а не доказательством нашего
  транслятора.
- PERSO/LUN‑60 путь как **основной компилятор** отвергнут: SIMH не грузит нашу
  библиотеку; системный ФОРЭКС той же версии делает вывод неразличимым.

## Правила

- Эталонные образы и листинги не изменяются; рабочие копии — вне репозитория.
- Статус этапа меняется только по факту: SIMH A/B, побайтовая сверка или
  документ‑результат.
- Версии `2.02 от 15.07.80`, `4.13 от 11.09.85` и `FOREX 412` — разные
  сборки и не смешиваются.
- Баннер `ВЕРСИЯ 2.02 ОТ 15.07.80` в эталонных прогонах печатает системный
  ФОРЭКС; версия изделия — FOREX 5.00 (`docs/16-glissade-run.md` §6).
- Пользовательские правки `tools/run_besm6_deck.py` и
  `tests/plan-f77/64-monitor-patch/` не трогаются.
