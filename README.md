# re-forex — FOREX 5.00 / 19.11.2026 (re-forex)

**Версия изделия: FOREX 5.00 / 19.11.2026 (re-forex).** Реконструкция компилятора
**ФОРЭКС (FOREX) ИПМ АН СССР** для БЭСМ-6.
Компилятор написан на автокоде МАДЛЕН/БЭСМ: корневой модуль `FOREX*` и два
последовательно загружаемых оверлея `LO*SYN` (синтаксис) и `LO*GEN`
(генерация кода). Входной язык — Фортран, близкий к Фортрану‑77.

## Статус

Оверлеи дизассемблированы и аннотированы; все регрессионные сценарии проходят.
Наш контур `*TRANS` (зона `0o2350`) доказан тестами `tests/plan-f77/66..85`;
финальный отчёт — [docs/73-release-report.md](docs/73-release-report.md).
План и разведка носителя — [docs/PLAN.md](docs/PLAN.md), состояние этапов —
[checklist/STATUS.md](checklist/STATUS.md).

**Изделие (одной фразой):** FOREX 5.00 закрывает всю матрицу F77 в доступном контуре (2.02 + F77PREP/F77LIBR + PERSO-мост АРФЫ): 200/200 элементов исполнимо здесь, из них 143 нативно, 56 только через понижение, 1 вне X3.9, и это не утверждение о нативной поддержке полного F77 в 4.13.

**F77 / верификация:** 6/6 гейтов rc=0 (dumps, prep 21/21, full gate 20/20 + L0/L1 55/55, глиссада 14/14, suite 8/8 + кросс `*FTN` 3/3, матрица 200/200). Стратификация — `docs/69-f77-stratification.md`, полный gate — `docs/68-f77-verification.md`, финальная приёмка — `docs/72-final-acceptance.md`. Нативный путь P7 остаётся `NEEDS-RUNTIME-REBUILD`.

**Наш контур `*TRANS`:** компилятор ставится в зону `0o2350` диска 2048 и вызывается штатной картой `*TRANS:OURMRK*,,412350`; `NEWCOMP*` не патчится. Цепочка «Fortran-дека → F77PREP → IR `FRONT.FTN` (`777001..777007`) → CODEGEN/EMIT → GOST-слова → `*TRANS` зона 2350 → `*64`» доказана тестами `tests/plan-f77/66..85`. Реальный дек `base.b6` даёт `21 01.00 03.00`, численно совпадая с gold; граница `6`/`5` меняет печать на `21`/`15`, `X`/`Y` извлекаются из IR (`X=2.0` → `21 2.00 4.00`). Границы: 58 чистых слов зоны `N+3`, machine insert — одно слово за раз, `DO`/`FORMAT`/`F77LIBR` остаются на системном пути. Подробности — `docs/73-release-report.md`.

**Машинные вставки и широкий вывод:** `BESM(hi,lo)` → IR `777006` (и `V=BESM(hi,lo)` → `777007`) по образцу pascal-re — `docs/71`, `tests/plan-f77/83-besm-insert/` (6/6 A/B) и `tests/plan-f77/85-multi-besm/` (9/9 A/B). Широкий вывод 4+2 разряда (`|v| ≤ 9999.99`, отрицательные) — `tests/plan-f77/84-wide-output/` (10/10 A/B). Обе возможности работают вместе в одной компиляции: `tests/plan-f77/86-combined-contour/` (9/9 A/B, две печати: исходная и изменённая вставками).

## Правила

- Эталонные образы и листинги не изменяются; рабочие копии — в `build/`.
- Статус этапа меняется только по факту: побайтовая сверка или документ-результат.
- Каждый найденный символ в листинге снабжается ссылкой `источник:строка`.
- Версии `2.02 от 15.07.80`, `4.13 от 11.09.85` и `FOREX 412` — разные
  сборки; хранятся все три эталона и не смешиваются. **Семантическая база
  реконструкции — FOREX 4.13** (Дубна, исходник корня `libra211.l21:15448-15528`,
  gold `reference/expect_forex.txt`); 2.02 — системный эталон dispak 2048 и
  bootstrap-компилятор этой среды.
- **Наша версия — 5.00.** Баннер `ВЕРСИЯ 2.02 ОТ 15.07.80` в эталонных
  прогонах печатает системный ФОРЭКС диска 2048 (проверено прогоном с
  PERSO-образом и без него). Константы 2.02/4.13 отсутствуют в наших модулях
  (база 4.13 задана исходником корня и gold-эталонами, а не баннером),
  поэтому патч невозможен: системный баннер 2.02 остаётся, а версия изделия —
  FOREX 5.00 / 19.11.2026. Метки `FOREX 5.00` и `19.11.2026` записаны в хвост
  PERSO-образа и в заголовки исходников; подробности — `docs/16-glissade-run.md` §6.
