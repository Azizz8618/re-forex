## 1. FORMAT-дескрипторы (вопрос: какие из F/E/D/G/A/L/X/,/H реально есть)
DESC_E    'FORMAT(1X,E12.4)'  X=3.5        -> OK   вывод: 3.5000+00
DESC_D    'FORMAT(1X,D12.4)'  X=3.5D0      -> OK   (уже OK в матрице J12)
DESC_P    'FORMAT(1X,1PE12.4)'             -> OK   вывод: 35.0000-01  (масштаб работает)
          ПРИМЕЧАНИЕ: 'FORMAT(1X,1P,E12.4)' (с запятой после 1P) -> FAIL
          'БЫЛИ ОШИБКИ ПРИ ТРАНСЛЯЦИИ ИЛИ В НАБИВКЕ'. Каноническая форма — 1PE12.4.
DESC_L    'FORMAT(1X,L1)'     L=.TRUE.     -> OK   (матрица J15 была UNKNOWN -> OK)
DESC_SL   'FORMAT(1X,F8.2/1X,F8.2)'        -> OK   ('/' работает, J18 UNKNOWN -> OK)
DESC_G    'FORMAT(1X,G12.4)'  X=3.5        -> FAIL 'ОШИБКА СПЕЦИФИКАЦИИ ФОРМАТА'  (J13confirm NO)
A6        'FORMAT(1X,A6)'  W=4HABCD        -> OK   (A с шириной работает)
A4        'FORMAT(1X,A4)'  W=4HABCD        -> OK
DESC_A    'FORMAT(1X,A)'   (без ширины)    -> FAIL 'АТТ 00506 ПК 2'  (нужна ширина A6)
E_1P      'FORMAT(1X,1PE12.4)'              -> OK   (duplicates DESC_P, контроль)

Вывод: в таблице 11 FT* реально присутствуют F, E, D, A(с шириной), L, X, /, H(nH),
       I. G ОТСУТСТВУЕТ (единственный FAIL among edit-дескрипторов).

## 2. IOSTAT / END= / ERR= (с ЯВНЫМ форматом, чтобы исключить list-directed *)
IOST_R10  'READ(5,10,IOSTAT=K) X'  + FORMAT -> FAIL 'БЫЛИ ОШИБКИ ПРИ ТРАНСЛЯЦИИ ИЛИ В НАБИВКЕ'
IOST_W54  'WRITE(54,10,IOSTAT=K) X' + FORMAT -> FAIL  то же
END_R10   'READ(5,10,END=99) X'            -> FAIL  то же
ERR_R10   'READ(5,10,ERR=99) X'            -> FAIL  то же
IOSTAT_R  'READ(*,*,IOSTAT=K) X'           -> FAIL 'НЕДОПУСТИМ СИМВОЛ * В ВЫРАЖ' (двойной отказ: * + IOSTAT)
END_EQ    'READ(*,*,END=99) X'             -> FAIL 'НЕДОПУСТИМ СИМВОЛ * В ВЫРАЖ'
ERR_EQ    'READ(*,*,ERR=99) X'             -> FAIL 'НЕДОПУСТИМ СИМВОЛ * В ВЫРАЖ'

Вывод: компилятор 2.02 НЕ распознаёт IOSTAT=, END=, ERR= ни в одной форме.
       Требуется либо F77PREP-lowering (обработка EOF в рантайме, ветвление),
       либо правка LO_SYN (NEEDS-MADLEN). 0 слов в оверлеях при lowering.
