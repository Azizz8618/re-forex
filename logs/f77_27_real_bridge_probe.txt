НАЙДЕННЫЕ РАСХОЖДЕНИЯ ABI (причина хостового адаптера):
  1) F77PREP-lowering объявляет INTEGER FM(20); реальная библиотека — FM(320).
     Симптом без адаптации: "НЕВЕРНАЯ ДЛИНА *FILMAP*" и FAIL case23.
  2) lowering: CALL ZFOPEN(NAME,LUN,FM(1)) (3 арг.);
     реальная библиотека: ZFOPEN(NAME,LUN,NZ,ISTAT) (4 арг.).
  3) Э70 переносит ровно 8 слов за вызов (unrolled copy в ZE70W/ZE70R).
     Разбиение 12-словного буфера на 2 вызова создаёт 2 физические записи
     и ломает однозаписный READ (проверено: case24 давал "С 0 D 0 0 0").
     Решение: не разбивать; нагрузка кейсов лежит в первых 2 словах.
  4) EOF реального моста — по лимиту записей FM(B+7) >= FM(B+6) (NZ).
     NZ=8 для case23-25; NZ=2 для case26 (второй READ -> ISTAT=-1).
  5) FILMAP реального моста требует инициализации (DATA FM /320*0/).
