--- Карта каталога PERSO (проверено на re-siprod/build/siprod.bin) ---
24576 слов = 24 зоны, 108 записей каталога.
w0 = 0o0000000002152140 (служебное), w1 = 0,
w2 = 0o6364415644410000 = TEXT 'STANDA  ',
w3 = 0o3750640013200000 -> length-поле 0o1320 = 720 = 90*8, overlay=0,
w4 = 'STAATP  ', w5 = 0o3450640023500000 (157*8) ...

Формула (notes/loader.md п.3):
    rec = (date << 24) | ((L*8) << 12) | overlay
    L = cmd+const+bss  (bss=ПАМ, НЕ data; loader.md п.1)
    у date младшие 2 бита должны быть 0; date взять из существующей записи.
Имя: 8 символов TEXT, 6 бит/символ, ' '=0, '*'=10, выравнивание влево.
Новые записи — ТОЛЬКО в конец каталога после завершателя (loader.md п.4).

--- Формула записи ---
Монитор:  лен 40(2348-wr)^ ; ... ; *to perso:402300 ; монитор печатает
          "ДЛИНА LIBRARY <NNN> ЗОН" (восьмеричное, включает 2 зоны каталога)
         LU = 30..67 (2 восьм. знака), ZZZZ = начальная зона (восьм.)
Raw:      BESM6_PATH=$HOME/.besm6 besmtool write 2348 --from-file=forex-lib.bin --start=1216
Контроль: besmtool dump 2348 --start=1216 --length=$NZ --to-file=/tmp/readback.bin ; cmp

--- Загрузка / разрешение имён ---
лен 60(2348)^ ; *call yesmemory ; *perso:602300  (== *PERSO:60 2300) ; *forex
Последняя загрузка имени побеждает: системную библиотеку грузить ПЕРВОЙ,
нашу — ПОСЛЕДНЕЙ (,cnt дозаписи). Имена: FOREX*, LO*SYN, LO*GEN, FORMAT,
DATAPR*, OCTTDEC.
