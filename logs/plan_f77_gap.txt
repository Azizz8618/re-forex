4. РЕЗУЛЬТАТ (после корректуры)
   - 21 позиция подтверждена исполнением; 5 позиций confirmed не работают
     (CHARACTER в 2.02, PRINT *, READ(*,*,END=), IMPLICIT NONE, SAVE);
     3 позиции нестабильны (~); 17 позиций требуют пробы (?).
   - CHARACTER — версионная зависимость: NO в 2.02 (§2.1) / OK в 4.13
     (Dhrystone CHARACTER*30, 18+4 контролей) → убрано из §1, добавлено в P1 плана.
   - Ключевое противоречие источников: старые таблицы §3/§6 dubna-languages.md
     приписывают ФОРЭКСУ «ч» для блок IF и − для многомерных массивов — артефакт
     подмены *forex -> *fortran, опровергнут пробами 2.02 и 4.13. Для строк
     старый «−» частично совпадает с 2.02, но опровергнут 4.13.
   - Приоритеты: P0 — 6-символьная коллизия имён и SAVE; P1 — версионная
     зависимость CHARACTER, list-directed I/O, IMPLICIT NONE, READ с END=;
     P2/P3 — остальное. Dhrystone (4.13)/Whetstone/glissade используют только
     подтверждённое для своей версии подмножество.
