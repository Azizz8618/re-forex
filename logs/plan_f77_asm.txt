--- 3. Ключевые решения дизайна ---
1. Подмена точечная: SYN → LO*SYN (зона 1517..1777), GEN → LO*GEN (таблица
   0532..0623 + inline-кодогенерация), диспетчер → FORMAT ( новая пара FT* ).
   FOREX*, DATAPR*, GIV/PG, TAK/PG, OCTTDE* не трогаем; F77LIBR — новая зона
   в конец каталога.
2. Оверлеи грузятся по одному адресу 0o22654 без релокации → каждый patched
   оверлей обязан остаться ровно 1024 словами; рост = перекомпоновка либо
   вынос в рантайм.
3. Проверка при изменённой симтаблице — слои L0..L5:
   golden SHA256 → сравнение поля КОП → homeomorphic mapping меток →
   функциональные тесты → manifest разрешённых диапазонов слов →
   воспроизводимость сборки. Manifest заменяет жёсткий 1024/1024 только для
  patched-модулей.
4. Гибрид: ассемблер — только точка входа (ориентир: ~10–25 слов на LO*GEN,
   30–60 на LO*SYN, 3–6 на FORMAT), вся семантика F77 — Fortran-модуль
   F77LIBR (~150–300 слов в отдельной зоне). Одна VJM на редкую
   F77-конструкцию вместо inline-роста в плотных таблицах.
5. Тесты: 16 сценариев (15 decks из tests/plan-f77 + GLISSADE 14/14), 4 новых
   позитивных F77-теста, контрольные векторы (слова/вывод/каталог/сборка),
   sliding-window (W=3, порог 0.95) сравнение с Фортраном-ГДР, помечаемое
   SKIP при отсутствии эталона.

--- 4. Оценки трудоёмкости (слов внутри 1024-словных оверлеев) ---
имя оператора в 0532..0623 : 2–5 слов, риск ВЫСОКИЙ (таблица упакована)
inline-кодогенерация LO*GEN : 10–40 слов, риск ВЫСОКИЙ
ключ+обработчик LO_SYN      : 30–90 слов, риск ВЫСОКИЙ (176 слов на 1517..1777)
FT* в FORMAT                 : 3–6 слов, риск СРЕДНИЙ/НИЗКИЙ (LINK 0o74014..077)
Fortran F77LIBR              : 50–150 слов новой зоны, риск НИЗКИЙ
