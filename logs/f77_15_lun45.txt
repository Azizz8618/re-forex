# КОД (extra.c:2131-2195), разбор:
#   ddio() — обработчик экстракода Э70. u = uir.i_opcode & 077 (номер диска).
#   Static l45_drum/l45_tract инициализируются из env:
#     BESM6_LUN45_DRUM  (strtol base 8), BESM6_LUN45_TRACT (base 8),
#     BESM6_LUN45_KCOUNT (адрес, пишется в core[0600] байты 4-5),
#     BESM6_DRUM_SEED / BESM6_DRUM_SEED_DRUM (заMOUNTка конверта на барабан).
#   Если BESM6_LUN45_DRUM >= 0 и u == 045, происходит redirect:
#     u = l45_drum; zone = l45_tract; dd = disks + u;
#   и сразу проверка `if (! dd->diskh) return E_CWERR` (строки 2205+).
#   Комментарий в коде: «Шаг 2ж (ГЛИССАДА): перенаправление чтения входного
#   потока задачи (монread% идёт по шаблону УИР 45/0 на диск) на барабан-спул
#   МОНЫ». То есть механизм обслуживает ВВОД МОНИТОРА (monread), а не
#   Fortran-юнит 45.
#
# ЭКСПЕРИМЕНТ (дек U45_W: WRITE(45,10) 45 ; U45_R: READ(45,10) X):
#  dispak U45_W, без env:
#     ...
#      НЕТ КАНАЛА  LUN 45
#      КОНЕЦ ЗАДАЧИ
#  dispak U45_W, env BESM6_LUN45_DRUM=41 BESM6_LUN45_TRACT=0:
#     ...
#      НЕТ КАНАЛА  LUN 45
#      КОНЕЦ ЗАДАЧИ
#  dispak U45_R, env BESM6_LUN45_DRUM=41 BESM6_LUN45_TRACT=0:
#     ...
#      НЕТ КАНАЛА  LUN 45
#      КОНЕЦ ЗАДАЧИ
#  Дополнительно: дек с картой `лен 45(2348-wr)^` (смонтирован writable том)
#     WRITE(45) → НЕТ КАНАЛА  LUN 45.
#  Причина: сообщение «НЕТ КАНАЛА» выдаётся средой ФОРЭКС 2.02 ДО выдачи
#  экстракода Э70 (таблица LUN монитора не содержит канал для юнита 45);
#  стало быть, redirect в extra.c:2139 до дела не доходит.
#
# ВЫВОД: НЕТ. Активировать Fortran-юнит 45 как дисковый канал без правки
# ре-forex НЕЛЬЗЯ. Env-переменные BESM6_LUN45_* — undocumented хук мониторного
# ввода, он не привязывает LUN к Fortran-юниту и не создаёт канал.
# Точные блокеры:
#   1. Таблица LUN/каналов монитора ФОРЭКС 2.02 (системный диск 2348):
#      юниты 40/45 не привязаны → «НЕТ КАНАЛА LUN 40/45»;
#      юниты 1/2/5/6/10 привязаны к devise, но без поточного канала →
#      авария *70 / ОШ.В ИНФ.СЛ.ЭКСТ при передаче данных.
#   2. Рантайм ввода не сигналит EOF/IOSTAT (очередь карт без EOF-маркера).
#   3. extra.c:2126-2194 — хук Э70 только для monread, не для Fortran LUN.
# Что нужно: правка монитора/рантайма ФОРЭКС (LUN-таблица + канал 45 +
# EOF-сигнал) — отдельная задача P7c/monitor, вне владения этой волны.
# Оценка: это НЕ оверлей (0 слов в 1024-словных оверлеях), но правка
# системной зоны/монитора на диске 2348 + рантайма dispak; по объёму
# сопоставимо с отдельным проектом (десятки чел.-дн.), не с правилом F77PREP.
