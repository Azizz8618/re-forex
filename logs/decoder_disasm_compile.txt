ПЕРВАЯ ПОПЫТКА (ОШИБКА)
-----------------------
DATAPR.masm -> *CALL DTRAN(DATAPR): DTRAN нашёл в библиотеке другой модуль
DATAPR (маленький PRINT8-подобный), НЕ DATAPR*. Листинг: 33 карты.
Исправление: переименовать в DATAPR%.masm -> *CALL DTRAN(DATAPR*).

КОМПИЛЯЦИЯ DATAPR*
------------------
$ BESM6_PATH=... WORKVOL=80 perl -CA asm.pl -keep DATAPR%.masm
*NAME / *NO LIST / *MADLEN
 DATAPR*:,NAME, ...
 DATA*:,LC,2
 *LIBRA:2
 *COPY:1,270000,600000
 *STAND
 *CALL DTRAN(DATAPR*)
 *EDIT / *R:1 / *W:600000 / *EE

MADLEN-3.5 статистика (из листинга с *LIST):
  ИМЯ 00001  ВХОДЫ 00003  ОПИСАНИЯ 00011
  КОМАНДЫ 00035  КОНСТАНТЫ 00022  ИНСТРУКЦИИ 00089
  ЧИСЛО ПЕРФ. 89   ЧИСЛО ОШИБ. ОПЕРАТОРОВ 00
  ФАЙЛ 1: СЧИТАНО 33 КАРТ; ФАЙЛ 600000: ЗАПИСАНО 33 КАРТ

Результат: disasm/RUNTIME_DATAPR.dtran_compiler.lst (83 строки COSY).

ПРЯМАЯ ПРОВЕРКА DTRAN (вспомогательная)
---------------------------------------
Тестовая сборка DMS с UTM (0o0a8000) + бит 18:
  extra=0x000000 hw=0o66507774 -> ' 13,UTM,7774B'   (правильно)
  extra=0x040000 hw=0o67507774 -> ' 13,V1M,7774B'   (бит 18 меняет opcode!)
=> бит 18 используется как расширение адреса ТОЛЬКО для opcode < 0o40000.

ПЕРЕКОДИРОВАНИЕ В МАШИННЫЕ СЛОВА
--------------------------------
2 МАДЛЕН-команды на 48-битное слово; DOUBLE WORD-литералы — полные слова.
DMS-заголовок: 0o200003 + 6-битное имя (как у LO_*SYN/GEN на ленте).
Энкодер: /tmp/.private/azizz/opencode/final_encode.py
